# devops-cli Documentation

`devops-cli` is a Python command-line tool that automates workstation, GitHub, Kubernetes and code-review work for the repositories it manages.

## Primary Guides

- [CLI Reference](CLI_REFERENCE.md) — The index of the `devops` command groups and the command matrix, with a link to the page of each group.
- [Configuration Reference](CONFIGURATION.md) — Configuration file hierarchy, settings, and validation rules.
- [FastMCP Tools](MCP_TOOLS.md) — Registered FastMCP tools for AI assistants and MCP clients.
- [Roadmap Workflow](ROADMAP_WORKFLOW.md) — The eight steps of an issue, its states, labels, actors and the three human gates.
- [devops-cli in the Cluster](CLUSTER.md) — The roadmap Service and its runner Jobs, Crawl4AI, SearXNG, the MCP server, and the pins and updates of the images.
- Roadmap jobs — [the package layout](roadmap/package-layout.md), and one page for each job: [intake](roadmap/intake.md), [refine](roadmap/refine.md), [alternatives](roadmap/alternatives.md), [stage](roadmap/stage.md), [implement](roadmap/implement.md), [inbox](roadmap/inbox.md) and [onboard](roadmap/onboard.md).
- [Routine Tasks](ROUTINE_TASKS.md) — Operational task matrix, cadences, and engineering methodology.
- [SDLC Workflow](SDLC.md) — Software development lifecycle and branch governance policies.
- [Testing Guide](TESTING.md) — Testing vocabulary, test doubles, and quality gate standards.
- [Design Spec](DESIGN.md) — The design tokens, their build, and the palette, type, layout, chart and table rules of each artifact.
- [SRE Spec](SRE.md) — The service catalog, the SLOs and error budgets, the alerts, the incidents, the change safety, the backups and the gaps with their issues.
- [AI and RAG Cheatsheet](cheatsheets/ai_and_rag.md) — Managed repository ingestion and semantic search reference.
- [Dashboard Tabs Audit](DASHBOARD_TABS_AUDIT.md) — Audit of five dashboard tabs against open terminal tools.
