**Scope**: scope/docs
**Feasibility**: Read at release/v0.2.39 (f4177632): `CONST_HANDWRITTEN_DOCS_PATHS` and the two collectors in `src/devops_cli/docs/markdown_argv_collector.py`, one for the knowledge base and one for seven listed documents and `k8s/**/README.md`, with a listed document that is missing skipped (`if not file_path.is_file(): continue`); and `DocGenerator.check_docs`, which called both. `git ls-files '*.md'` holds 821 files. The knowledge base, the prompts and the rest of the hand-written documents resolve cleanly. `DocGenerator.generate_all_docs` returns the seven top-level references, `commands/*.md` and a `README.md` entry for the synced command matrix; `CLAUDE.md` and `.github/copilot-instructions.md` are written by `generate_instruction_content` and held byte for byte by `tests/test_agents_md_claims.py`. `docs/cheatsheets/security_and_ssh.md` was read by `tests/test_vulnerability_lookup.py`, which the issue's file list omits.

## Description

Documents drifted from the code because nothing said which documents there are or what keeps each true. `devops docs check` resolved the command lines of a hand list of seven documents, the knowledge base and the `k8s` READMEs, so the other hand-written documents and the prompts were unchecked, and nine cheatsheets named commands that do not exist (`devops tofu`, `devops docker ps`, `devops scan all`). This is the first of two pull requests for #1103; the coupling gate is the second.

- **The inventory** is `CONST_DOCS_INVENTORY` in `src/devops_cli/config/constants.py`: a table from five classes to the path globs of their documents, replacing `CONST_HANDWRITTEN_DOCS_PATHS`. The classes are generated (`docs/CLI_REFERENCE.md` and the other generated references, `docs/commands/*.md`, `CLAUDE.md`, `.github/copilot-instructions.md`), release artifact (`CHANGELOG.md`, `docs/ROADMAP.md`, `docs/RELEASE_NOTES.md`, written by the cut), record (task files, ADRs, the archive and `changelog.d/<n>.md`, which are history and are never rewritten to match later code), prompt (`src/devops_cli/ai/tasks`, `ai/prompts` and `ai/personas`) and hand-written. The hand-written class is listed by path, with globs for `k8s/**/README.md` and the knowledge base, not "every other Markdown file": a class that took everything unlisted could never leave a new file unclassified. `README.md` is hand-written although `DocGenerator` syncs its command matrix.
- **The name gate** is one collector, `collect_documented_argv_references`, with `check_documented_argv`, in `src/devops_cli/docs/markdown_argv_collector.py`. It reads the hand-written and prompt classes (`CONST_DOCS_NAME_CHECKED_CLASSES`) from the inventory, replacing the knowledge-base and hand-written collectors, and `DocGenerator.check_docs` calls it. An entry that names one document and matches no file is reported (`MESSAGES.docs.inventory_entry_missing`), where a missing listed document was skipped. An entry with a glob wildcard (`is_pattern_entry`: `glob.escape(entry) != entry`) is a pattern, not a document: the files it matches depend on the release phase (`changelog.d/[0-9]*.md` matches nothing between the cut, which deletes every fragment, and the first fragment of the next release, and a `Part of #<issue>` pull request adds none), so a pattern is held to the classification checks but not to matching a file.
- **Deleted**: `docs/cheatsheets/` (9 files) and its `README.md` link. The commands they did show are in the generated `docs/CLI_REFERENCE.md`, and nothing moves elsewhere. `tests/test_vulnerability_lookup.py` no longer reads the deleted security cheatsheet.
- **Reworded**: `docs/SELF_IMPROVEMENT.md:1095` said "`devops ai benchmark --suite` is gone", which names a removed option as a command line. It says "The benchmark's `--suite` option is gone".
- **Documented**: `CONTRIBUTING.md` states that a pull request that adds a document lists it in the inventory, and that `devops docs check` resolves the command lines of hand-written and prompt documents.
- **Tests**: `tests/test_docs_inventory.py` holds the checks below. `tests/test_docs_knowledge_base_argv.py` and `tests/test_docs_source_argv_collector.py` patch the one collector, and the two whole-tree tests that read the old lists moved into the inventory test.
