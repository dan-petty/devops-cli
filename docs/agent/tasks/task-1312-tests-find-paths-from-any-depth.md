## Description

Every test module finds the repository root and its test data from one place, so a module reads the same paths at any depth, and `devops test` maps a change through the selector `devops ci test` uses. The item is delivered as five pull requests, in the order of the plan on the issue.

**`tests/support/` and the shared paths (PR 1).**

- **The package.** `tests/support/__init__.py` says what lives there; `tests/support/fakes/__init__.py` says it holds one fake per external edge, each with its contract suite. No test file lives under `tests/support/`.
- **The paths.** `tests/support/paths.py` defines `TESTS_ROOT = Path(tests.__file__).resolve().parent`, `REPO_ROOT = TESTS_ROOT.parent`, `FIXTURES = TESTS_ROOT / "fixtures"` and `GOLDEN = TESTS_ROOT / "golden"`. They are constants, not fixtures, because module-level constants and `parametrize` lists need a path at import.
- **The readers.** The 91 `Path(__file__)` sites in 63 modules are converted: each module drops its own root constant (`REPO_ROOT`, `_REPO_ROOT`, `_ROOT`, `ROOT`, `_PROJECT_ROOT` and function-local `repo_root` and `root`) and imports the shared one; a fixture or golden read becomes `FIXTURES` or `GOLDEN`. `tests/test_review_score.py`'s own `FIXTURES`, the review labels directory, is now `REVIEW_LABELS`. The four root-relative reads of test data (`tests/test_k8s.py`, `tests/test_review_rules_pack.py`, `tests/test_stack_dashboards.py`, `tests/test_review_prompt_consistency.py`) and the two working-directory reads (`tests/test_sandbox_traces.py`) read `FIXTURES`.
- **The ratchet.** `tests/test_swallowed_failures_ratchet.py` imports `tests.support.paths`, so it runs as a module. `CONST_LOWER_COMMAND` is built from `__spec__.name`, `uv run python -m tests.test_swallowed_failures_ratchet --lower`, which follows the module if it moves, and the usage line prints it.
- **Left for PR 5**, because each file is changed by a pull request in flight when PR 1 was written: `tests/conftest.py` (3 sites, PR 3 of this item); `tests/test_roadmap_config.py` (1 site, #1345 PR 1, #1683); `tests/test_roadmap_github_store.py` (1 site) and `tests/test_github_session.py` (1 site), #983 PR 5; `tests/test_k8s_argocd_apps.py` (1 site) and `tests/test_k8s_devops_stack.py` (3 sites), #1154 PR 2. PR 1 also leaves untouched, for the same pull requests, `tests/test_github_pr_monitor.py`, `tests/test_pr_cmd.py`, `tests/test_github_copilot_budget.py` and `tests/copilot_review_payloads.py` (#1683), `tests/test_roadmap_store_contract.py`, `tests/test_github_ssh.py`, `tests/github_session_fakes.py` and `tests/test_github_errors.py` (#983 PR 5) and `tests/test_k8s_agents_manifests.py` (#1154 PR 2), none of which reads `Path(__file__)` at a153042.

**`devops test` maps a change through the shared selector, and a `tests/support/` change forces a full `devops ci` run (PR 2).**

- **`devops test run --changed`** keeps its git listing, the branch's diff against `main` and `git status --porcelain`, now with `--untracked-files=all` so each file of an untracked directory is listed by its own path, and a rename by its new path, and hands the changed paths to `select_tests_for_sources`. The listing is against `main`, so on a topic branch cut from a release branch it covers the whole release, which changes `tests/conftest.py` and `tests/support/`, and the whole suite runs; `_changed_paths` diffs against `CONST_GIT_MAIN_BRANCH`, and the `base_ref` parameter no caller passed and its ref pattern are gone. Its flat name table, which matched `test_<stem>.py`, `test_<stem>_cmd.py` and `test_commands_<stem>.py` directly in `tests/`, is deleted with `find_changed_test_files`; the shared selector matches by name at any depth and by import. It runs the returned targets that exist, so a deleted test module is never passed to pytest, and the whole suite when nothing changed or nothing maps. Each changed source no test module covers is named through `MESSAGES.test.unmapped_source`, and the run's other two lines moved to `TestMessages` too.
- **The selector's new rules.** A changed module in a subpackage of `devops_cli` also selects the test modules directly in `tests/<subpackage path>/` when that directory exists, not those in its subdirectories, and a package's `__init__.py` selects its own directory; a module directly in `devops_cli` gets no mirror rule, because `tests/` still holds every test module not yet moved. A changed `conftest.py` below `tests/`, or a test package's `__init__.py`, selects its directory, where it was left unmapped. A change that forces a full `devops ci test` run (`forces_full_run`: a file under `tests/support/`, a conftest in the repository root or directly in `tests/`, `pyproject.toml`, `uv.lock` or `.python-version`) selects `tests` at once, before any test module is listed or read: the 877 paths this branch lists against `main` select in 0.003 s, where the selection pass took 26 to 73 s. `devops ci test`'s text fallback calls the same selector, so its mirror rule applies there too.
- **`devops ci` treats `tests/support/` like a conftest.** `_FULL_RUN_TRIGGERS` moved to `src/devops_cli/config/constants.py` as `CONST_FULL_RUN_TRIGGER_NAMES`, beside `CONST_CONFTEST_FILENAME` and the new `CONST_TEST_SUPPORT_DIR`. A public `forces_full_run(path)` in `src/devops_cli/core/coverage_index.py` holds the rule, and both `_check_trigger_files` and `select_from_index` use it, so `uv run devops ci test tests/support/paths.py --no-fallback` exits 1 naming the file, and without `--no-fallback` the full suite runs. `_normalize_repo_rel_path` drops only a leading `./`, where `.lstrip("./")` also dropped the dot of `.python-version` and the `../` of a parent path, so `devops ci test .python-version --no-fallback` refuses like the other trigger names instead of passing with nothing run.
- **Ceilings.** `find_changed_test_files` and `run_test_cmd` no longer carry `# noqa: C901` (`_changed_targets` and `_porcelain_path` hold what made them long), and `DEFAULT_C901_SUPPRESSION_CEILING` falls by 2, from 49 to 47.
- **Hook-speed work left alone.** The selector still reads the test tree on each call that does not reach the whole suite, and now also lists one mirror directory per changed source module; reading the tree once per run, and showing the unmapped staged sources in the commit hook, are #1667 and its folded amendments. #1664's thread waits and the narrowed worker count are not touched.
