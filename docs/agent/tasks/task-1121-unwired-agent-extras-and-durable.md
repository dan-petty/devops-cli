**Scope**: scope/ai, scope/config

It reaches `ai/agents/spend.py` only through the string in `CONST_DOMAIN_EXCEPTION_MODULES`. The `importlib` and `__import__` sites in `src` take their module names from tables that list none of the six, and the only `ai.agents.*` name in a shared list was `devops_cli.ai.agents.spend` in `CONST_DOMAIN_EXCEPTION_MODULES`. A `git grep` over the whole repository for every public symbol of the six modules found references only in the deleted modules, their own tests, three single tests in other files, `docs/ERRORS.md`, `docs/CONFIGURATION.md` and the generated settings. `k8s/`, `.github/` and `config.example.yaml` name none of it. Temporal, DBOS and Prefect are not declared in `pyproject.toml` or locked in `uv.lock`, and `git grep -i -E 'temporalio|dbos|prefect|temporal(_|\]|durab|")' -- src tests` prints nothing afterwards. `AIConfig` ignores unknown keys (pydantic's default), so a `config.yaml` with an `ai.durable` block still loads. ## Description
The durable engine offered Temporal, DBOS and Prefect bridges that nothing could select (their packages were never declared, and a run is durable only inside the engine's own workflow), a local SQLite step store behind them, and an `ai.durable` settings block that no code read. Next to it sat four agent capabilities that copied what pydantic-ai and its harness ship (media externalisation, step persistence, versioned managed prompts, spend budgets) and a synthesis-protocol orchestrator with no caller. All of it is deleted with its tests. No shim replaces it: if a durable engine or one of those capabilities is wanted later, it is built together with its consumer from pydantic-ai's own `durable_exec` and capabilities, pinned exactly.

- `ai/durable.py` and `ai/agents/media.py`, `persistence.py`, `prompt.py`, `spend.py` and `synthesis_protocol.py` are deleted.
- `AIDurableConfig` and `AIConfig.durable` leave `config/settings.py`, and the row leaves `docs/CONFIGURATION.md`. The five `DEFAULT_AI_DURABLE_*` constants, `DEFAULT_SQLITE_MEMORY_DB_PATH`, `DEFAULT_MEDIA_EXTERNALIZER_ID` and `DEFAULT_MEDIA_OCTET_STREAM_TYPE` leave `config/defaults.py` and `config/__init__.py`.
- `BudgetExceededError` was defined in `spend.py`. It goes with `devops_cli.ai.agents.spend` in `CONST_DOMAIN_EXCEPTION_MODULES`, and `docs/ERRORS.md` is regenerated without its row.
- Orphans of the deletion: `security.sanitizer.sanitize_prompt_injection` (its only caller was `ManagedPrompt`) is deleted with its lazy-export entries in `security/__init__.py`, and `CONST_PROMPT_INJECTION_TAGS_RE` and its `CONST_PROMPT_INJECTION_TAGS_REGEX` alias are deleted with it. `ai.format_prompt.format_prompt_data` (its only caller in `src` was `ManagedPrompt.format_xml_variable`) is deleted with its `__all__` entry and its test, which leaves `ai/format_prompt.py` with the `format_as_xml` re-export that `ai/response_cache.py` imports. The three `DEFAULT_XML_*` defaults only `format_prompt_data` read leave `config/defaults.py` and `config/__init__.py`. A scan of every top-level name and class member in `src`, against the tree before #1869, at release/v0.2.39 ab595c10 and after this change, finds no other name that lost its last reference to this change or to #1869 (`TokenBucketRateLimiter.available_tokens` and the `AgentSpec` fields `deps_schema` and `end_strategy` have no reader, but they had none before either), and the import graph finds no module that lost its last importer. `docs/TESTING.md` no longer lists durable backends among the faked edges, since no test fakes one.
- `pyproject.toml` loses the `DEP001` list of `[tool.deptry.per_rule_ignores]` (`temporalio`, `dbos`, `prefect`) and its comment. `uv run deptry src` passes.
- Tests: the six test modules written for the deleted code are deleted. The three single tests that reached it from other files are deleted with it: the `DiskMediaStore` traversal test in `tests/test_runtime_security_and_ssrf_hardening.py` (whose sections are renumbered), the `ManagedPrompt` formatting test and the `format_prompt_data` test in `tests/test_pydantic_ai_format_prompt.py`, and the durable masking and `sanitize_prompt_injection` tests in `tests/test_consolidation_security_sanitizer.py`. `mask_secrets` keeps its own tests. `tests/test_config_commands.py` gains `test_a_config_file_still_holding_the_removed_ai_durable_block_loads`. `tests/test_ai_agent_capabilities.py` gains `test_embedding_cost_of_an_unpriced_local_model_follows_the_pricing_registry`, which keeps the one check of live code that `tests/test_ai_agent_spend.py` held: the `EmbeddingResult.cost` fallback prices a local model at 0.0, prices 100000 tokens at 0.15 once `set_custom_pricing` sets 1.5 per million, and passes the provider and request timestamp to `calculate_request_cost`.
- The shared lists follow the deletion: the `ai/durable.py` entry of the bare-exception list in `tests/test_architectural_invariants.py`, the `ai/durable.py` and `ai/agents/prompt.py` keys of `tests/fixtures/swallowed_failures_ceilings.json`, and the ceilings the deleted files made loose, measured with the suppression collector of `tests/test_architectural_invariants.py` on the tree rebased onto release/v0.2.39: `src type: ignore` falls from 67 to 64, `src noqa: F401` from 21 to 15 and `tests type: ignore` from 138 to 136. The C901 ceiling stays at 25, because the deleted files carried no C901 marker. The swallowed-failure ceilings measure the same as the fixture, so only the two deleted files leave it.
