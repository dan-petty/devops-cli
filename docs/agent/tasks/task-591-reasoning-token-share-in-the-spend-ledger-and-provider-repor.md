## 1. Description & Objectives

Nothing records reasoning tokens. Two FSMs isolate `<think>` blocks (`ai/thinking_stream.py:51`, `ai/client/streaming.py:23`), and each provider reasoning delta is rewrapped in its own `<think>…</think>` (`streaming.py:252,279,299`). `LLMResponse` carries `thinking` text beside prompt/completion/total tokens (`ai/client/models.py:84-87`); the ledger (`ai/spend/ledger.py:33-35`), both token exporters (`ai/spend/prometheus.py:86-87`, `ledger.py:486-487`) and the span token attributes (`ai/client/unified.py:82-89`) have no reasoning field. Stream spend is hand-counted: `_record_stream_spend` runs `count_tokens` over the joined chunks (`unified.py:809,833`). Both stream callers (`ai/agents/agent.py:1110`, `commands/ai.py:942`) keep the default `sanitize=False` (`unified.py:738,766`), so reasoning and its wrapper tags inflate completion tokens with no split. #479 infers "much of it on reasoning" with no record behind it. vibes `patterns/streaming-reasoning-isolation-and-token-budgeting.md` budgets what reasoning may cost but caps only a character buffer (`max_thought_chars`).
