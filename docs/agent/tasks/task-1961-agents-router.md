**Scope**: scope/ai
**Feasibility**: The author read AGENTS.md (36,534 characters at `4ed262a7`), the pointer stubs, `src/devops_cli/ai/instruction_generator.py`, the `devops ai agents` command, every routed document and the prompts, personas and knowledge base under `src/devops_cli/ai/`. ## Description

AGENTS.md is a router of 6,221 characters. It holds the purpose of the project, 13 rules that every task needs, one paragraph on what only a person does and on releases, and a table that sends each kind of task to the document that owns it. Each rule that it held before is in its owner, or is deleted because no current process needs it or because it repeated another rule.

- [x] **Router**: AGENTS.md holds the rules for every task and a table of 15 rows. The owner decisions of 2026-10-23 apply: an agent returns an item to `New` itself (`devops roadmap return --confirm`), the rule "Continuous Interaction & Collaborative Value Improvement" is deleted, and release-please writes `CHANGELOG.md`, `.release-please-manifest.json` and the version lines while agents change the release workflow through ordinary pull requests. The rules "Agents take no part in releases", the release pull request exclusion of the FIFO rule and the `Release-As` rule are deleted. `CONST_AGENTS_MD_MAX_CHARS` is 6,500.
- [x] **Rules moved to their owners**: `CONTRIBUTING.md` holds the `match` rule, the closed-list and parser rule, the constants rule, the naming rule, the line-break rule, the fail-to-pass rule and the helper-script rule. `ARCHITECTURE.md` section 7 holds the closed tool schemas, the process-group, `RLIMIT_NPROC` and `O_NONBLOCK` rules, the backoff rule and a new "Files" section. `SECURITY.md` holds the gitignored-file rule, the internal-service SSRF rule and the new principles 8 (repository hygiene), 9 (no phone-home) and 10 (bounded error detail). `docs/TESTING.md` holds the `example.com`, Bandit, socket and `RLIMIT_NPROC` rules. `k8s/README.md` holds the stack registration rule. `docs/SDLC.md` Phase 6 holds "Process only your own pull requests".
- [x] **Generator**: `devops ai agents` renders the router from `src/devops_cli/templates/AGENTS.md.j2` and the stubs from `pointer_stub.md.j2`. The router names no path, setting or dependency of devops-cli and no writing standard. Its table has a row for each document of `CONST_AGENTS_MD_ROUTES` that exists in the target. Its push rule names the pre-push hooks of the target, or the uv defaults. `is_devops_cli`, the alpha notice of the stubs, the f-string template and its `# nosec B608` are deleted, so the `src nosec` ceiling is 13. The inline prompt of `src/devops_cli/commands/ai.py` is in `src/devops_cli/ai/tasks/generate_agents.md`. The model gets the size cap and the documents that exist, and an answer longer than the cap is replaced by the template.
- [x] **Stubs**: `CLAUDE.md`, `GEMINI.md` and `.github/copilot-instructions.md` are regenerated by `devops ai agents --template --file <stub>`. They say that AGENTS.md holds the rules for every task and routes each task, and they repeat no rule.
- [x] **Legacy process removed**: The routed documents, the prompts, the personas and the knowledge base name no release branch, cut, changelog fragment, `Part of #`, planner command, roadmap document, `devops release` command or filing quota. `docs/SDLC.md` and `docs/ROUTINE_TASKS.md` plan a multi-step change as an OpenSpec change and keep no task status in a task file. The card moves to In Progress through `devops gh project sync`, and no rule asks an agent to move it earlier. The knowledge base names the registered MCP tools (`gh_issues_*`, `gh_milestones_*`, `gh_views_spec`, `gh_labels_*`). The obsolete "Criteria Inversion" guard of `.devops/review.md` is deleted, and its snapshot is regenerated.
