# Task: Intake Files Every New Candidate, With No Agent Filing Quota (#1959)

**Issue**: [#1959](https://github.com/dan-petty/devops-cli/issues/1959)
**Scope**: scope/roadmap
**Feasibility**: The author read `src/devops_cli/roadmap/quota.py`, `intake.py`, `intake_requests.py`, `config.py`, `run.py` and `src/devops_cli/commands/roadmap.py` at `90f7d888`. `git grep` found every reader of the quota: `read_quota`, the decision for each candidate, the quota line of the report, and six REST search counts in the dry-run plan. Only `read_quota` called `RoadmapStore.count_issues`. The quota was also the only reader of `RoadmapConfig` and of the run time in `plan_intake`. Before the change, the new test filed an agent candidate on a board with 162 open items and 12 agent openings of that day. Intake folded the candidate, filed nothing and printed the quota line. The test uses the in-memory store and a fake model.

## Description

The owner decided on 2026-10-23 that issues for future work need no restriction. Intake now files every new candidate that is not a duplicate, and its report names no quota. Intake still labels the candidate of an agent `source/agent` and checks it for a duplicate. It gives the candidate a type, a Priority, a Value and an Effort, and puts it in the backlog.

- [x] **Quota deleted**: `src/devops_cli/roadmap/quota.py` and `tests/test_roadmap_quota.py` are deleted. Intake has no `QuotaStanding`, `read_quota`, `QuotaDecision`, `BorrowReason` or `Outcome.FOLD`. No candidate folds into its nearest item, and no candidate borrows.
- [x] **Duplicates kept**: A duplicate issue closes as a duplicate of its original. A new candidate that is a duplicate is not filed, and the report names the original. [#1755](https://github.com/dan-petty/devops-cli/issues/1755) tracks how the model judges a duplicate.
- [x] **Reads**: A run makes no REST search count, and the dry-run plan shows none. `RoadmapStore.count_issues`, `IssueQuery`, `issue_search_text` and `issue_count_args` are deleted from the protocol, the GitHub store, the in-memory store and the request plan.
- [x] **Settings**: `.github/roadmap.toml` and `RoadmapConfig` have no `quota_*`, `open_issue_limit`, `throttle_start_fraction` or `overage_step_fraction` key. `src/devops_cli/config/defaults.py` has no default for them. `plan_intake` and `intake_candidate` take no `config` and no `now`. The intake job of the Service does not read `.github/roadmap.toml` for them.
- [x] **Command and MCP tool**: `devops roadmap intake` has no `--borrow-reason` option, so the `roadmap_intake` tool has no `borrow_reason` parameter. The help of `--filed-by` names only the `source/agent` label.
- [x] **Labels, constants and strings**: `.github/labels.yml` has no `budget/borrowed` label, and the description of `source/agent` is "Filed by an agent". `CONST_ROADMAP_BORROWED_LABEL` and `CONST_ROADMAP_BORROWING_PRIORITIES` are deleted. The quota line, the fold lines, the borrow note, the count requests and the two `--borrow-reason` errors are deleted from the message catalogue.
- [x] **Instructions**: `AGENTS.md` and the instruction generator name no filing quota, no borrowing and no `budget/borrowed` label. `devops docs generate --sync-readme` regenerated `README.md`, `docs/CLI_REFERENCE.md`, `docs/MCP_TOOLS.md` and `docs/commands/roadmap.md`.
- [x] **Tests**: `test_an_agent_candidate_is_filed_however_many_issues_agents_opened_recently` failed before the change and passes after it. `test_every_agent_issue_filed_outside_intake_is_placed` and `test_a_duplicate_agent_candidate_is_not_filed_and_the_report_names_its_original` replace tests of the quota. The roadmap configuration tests check the two keys that stay. The generator test fails when the template names a filing quota or `budget/borrowed`. The MCP argument tests use the choices of `filed_by`.
- Pending a person: `devops gh labels sync` deletes no label. After the merge, a person deletes the `budget/borrowed` label of the repository on GitHub.
