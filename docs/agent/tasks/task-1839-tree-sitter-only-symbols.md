# Task: Tree-Sitter Alone Parses Symbols and the Unreferenced AST, Cache and Reranker Helpers Are Deleted (#1839)

**Issue**: [#1839](https://github.com/dan-petty/devops-cli/issues/1839)
**Scope**: scope/ai
**Feasibility**: Every language the regex parser handled (python, typescript, tsx, javascript, go, rust, java, hcl, csharp, c, cpp, bash, markdown) has a grammar pinned in `pyproject.toml` beside tree-sitter 0.26.0, so the fallback guards (`find_spec`, `_check_native_tree_sitter`) guarded an install that cannot occur. At the base tip, a script that parsed every Python, Markdown and HCL file of the repository both ways found 1,971 files (1,130 Python, 829 Markdown, 12 HCL): tree-sitter found symbols in 1,861, both parsers found none in the other 110, and the regex parser decided none. The same script over about 59,000 third-party files found it decided 65 (0.11%). `git grep` showed no caller in `src/` of `ast_stream`, `ASTCache`, `global_ast_cache`, `rag/cache.py`, `CrossEncoderReranker` or `budget_diff_chunks`, only tests and one knowledge base article. Running the engine's query against tree-sitter 0.26.0 showed the premise of the old query path false: `Language` has no `query` method, so `query_code` always raised, `except Exception` swallowed it, and `_matches_sexpr_filter` answered every query by looking for words such as `function` in the query text.

## Description

- [x] `ai/ast/fallback.py` and the fallback branch of `TreeSitterEngine` are deleted. `parse_code` returns what tree-sitter finds, and a map with no symbols for a language without a grammar or a grammar that fails to load or parse. `FallbackASTParser`, `PolyglotFileMap.parse_engine`, `_matches_sexpr_filter`, `_check_native_tree_sitter` and the `find_spec` guards are gone, and the wording that described a fallback is removed from the engine, `ai/inspection.py` and `docs/SELF_IMPROVEMENT.md`.
- [x] `TreeSitterEngine.query_code` runs the S-expression with `Query` and `QueryCursor`, the tree-sitter 0.26 API, and answers with the captured nodes in source order, each with its capture name as `kind`. A query the grammar cannot compile raises `tree_sitter.QueryError`, which `devops ai ast parse --query` reports as `Invalid tree-sitter query: <reason>` with exit 1.
- [x] `ai/ast_stream.py`, `ai/ast_cache.py`, `ai/rag/cache.py`, `CrossEncoderReranker` (a keyword-coverage scorer, not a cross-encoder) and `budget_diff_chunks` are deleted with the tests that only exercised them, and the knowledge base article `it_domains/tools/tiktoken.md` no longer documents `budget_diff_chunks`. `_extract_symbols_from_tree` moved into `extract_python_source_symbols` in `ai/analyze/symbols.py`, its only caller. `DEFAULT_DIFF_CHUNK_BUDGET` stays: `devops ai token-count` uses it.
- [x] `validate_category` builds its own `TreeSitterEngine`; the engine argument only existed to inject a regex-only engine. The sample validation report no longer has a problem for a language read by the regex fallback, and loses `FileResult.parser`, `CategoryReport.parsers` and the Parsers column of `devops review samples validate`: `ast_language` already says whether tree-sitter read the file.
- [x] The swallowed-failures ceiling of `ai/ast/engine.py` is 2, and the key of the deleted `fallback.py` is gone.
- The regex parser's recall on files tree-sitter returns nothing for is lost: items inside Rust `macro_invocation` bodies (tokio's `cfg_*!{}`), `.d.ts` `export function` signatures (TypeScript's `function_signature` node is not in `NATIVE_KIND_MAP`) and mocha `it()` and `before()` calls. Adding `function_signature` is one line and one test, left to a person's decision.
- [x] `PolyglotSymbol.docstring` is deleted with its `to_dict` key (the symbol JSON of `devops ai ast parse --json` and `devops ai ast graph --json` loses `docstring`; pre-1.0, no shim), since only the regex parser's Python path ever filled it. The polyglot outlines of `ai/inspection.py` and the repository map of `ai/repomap.py` stop passing it, and `_extract_symbol_body` in `ai/ast/graph.py` drops the guard that returned it.

## Acceptance Criteria

- [x] No `fallback-ast`, `FallbackASTParser`, `ASTCache`, `stream_ast_symbols`, `EmbeddingCache`, `CrossEncoderReranker` or `budget_diff_chunks` remains in `src/`, `tests/` or the generated docs.
- [x] `tests/test_treesitter_engine.py::test_query_answers_with_the_nodes_it_captures`, `::test_a_malformed_query_raises_instead_of_answering_with_symbols` and `tests/test_ai_ast_cli.py::test_ast_parse_rejects_a_malformed_query` fail at the base and pass.
- [x] The fallback's pin of the declaration-line signature is kept native-only as `test_symbols_are_signed_with_their_declaration_line`, and `test_python_source_symbols_name_declarations_assignments_and_methods` pins the symbols `extract_python_source_symbols` returns, the coverage the deleted cache test gave `_extract_symbols_from_tree`.
- [x] `devops ci` passes.
