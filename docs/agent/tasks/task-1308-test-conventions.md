## Description

The owner settled the test design on 2026-10-07 (#1307). The rules agents and contributors read were scattered over AGENTS.md, the contributor guides, the review conventions and the knowledge base, and several contradicted the decisions: AGENTS.md required linear asserts to be merged into tuple comparisons on a false premise, since Ruff's C901 does not count asserts; it named one test file per submodule as canonical; and it called for mock isolation and for `__test__ = False` on test helpers in `src/devops_cli`. A complete draft (d3d01f1, 2026-10-07) was never pushed; this pull request brings it onto today's tree.
