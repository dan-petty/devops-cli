## 1. Description & Objectives

`AGENTS.md:160` grounds every change in an issue and a `docs/agent/tasks/task-<issue>-<slug>.md` file, and `AGENTS.md:65` and `:178` require that file Done, every box `- [x]`, in the delivering commit. Since #489, `tests/test_agent_task_files.py:31-35` checks only the issue link, no `**PR**` field and the status enum. `_evaluate_pr_blockers` (`commands/pr.py:1304`) never reads issues or task files. PRs into release branches get no native issue link, so an issue closes only through the body's closing keyword (`github/issue_closure.py:241`). `project sync` parses every task file (`commands/gh.py:551`) and counts it as synced (`github/projects.py:1485`), but writes only issues and PR-derived fields; `lang/en/help.py:746`, `docs/MCP_TOOLS.md:70` and `docs/agent/tasks/README.md:13` repeat the claim. vibes claims 100% issue-to-commit traceability and warns of 'sycophantic completion'.
