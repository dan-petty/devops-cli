## Description
The release model ran through a `release/vX.Y.Z` branch, a hand-made cut pull request, a release pull request of 188 to 990 files and a publish on the push to `main`, at 75 to 107 minutes and about 9,900 lines of dedicated code, tests, workflow and documents. [ADR 0011](../../adr/0011-releases-come-from-trunk-towncrier-uv-and-semver-tags-instead-of-a-bespoke-cut.md) decides that releases come from trunk: item pull requests target `main`, `towncrier` assembles the changelog from typed fragments, `uv version` sets the version, one dispatched workflow opens the release pull request, merging it publishes and creates the tag as its last write, and Argo CD follows the semver tags. It answers the five questions of the issue, measures v0.2.36 and v0.2.37, compares four options, names what stays custom with the open tool considered for each, and decides the ten points that needed the owner under "Decisions Taken". This pull request is the decision record only: no code, workflow or setting changes, and nothing in it publishes or deploys.
