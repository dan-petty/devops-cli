## Description
`ai/common_tools.py` held a web fetch tool with its own renderer for untrusted pages. It also held a DuckDuckGo HTML scraper and wrappers for the Tavily, Exa, X search and image generation tools. It had about 180 lines of try/except fallbacks for pydantic-ai tools that are not installed. It had mirrored result `TypedDict`s. After #1836 deleted the harness agents, nothing in `src` called any of it. The one live caller is `roadmap/refine.py`, which posts a query with `tavily_search`. `agents/guardrails.py` held the guardrail capability and `PromptInjectionDefender`. Only the page renderer called `PromptInjectionDefender`. This item deletes both modules except `tavily_search`.

A later feature may need web fetch or search. That feature uses `pydantic_ai.common_tools` (`web_fetch`, `duckduckgo`, `tavily`, `exa`). The native tools add no boundary tag and no prompt-injection scan. The feature wraps their output in a boundary tag and adds the scan. It registers the tag in `_PROMPT_BOUNDARY_TAGS`, so the sanitizer escapes the tag in untrusted text. The repository rule keeps a string list for matching in `config/constants.py` or `config/defaults.py`.
