## Description
Every point written by `WorkspaceIndexer` (`devops ai rag index` and `index-kb`) carries `embedding_model` in its payload. Before indexing into a collection that already holds points, the indexer checks that existing points were generated by the active model and match its vector dimension. If another model or dimension is found, indexing fails with exit 1 and a message naming both models and the corrective command (`devops ai rag clear --force`, then `devops ai rag index --force`). `--force` does not delete or recreate the collection on its own.

A search whose dimension does not match never deletes or recreates the collection. `_handle_dim_mismatch` is deleted, and searches raise a permanent `EmbeddingsError` (`is_transient=False`) naming the collection, dimensions, and the corrective command. Search also verifies model compatibility once per process, raising before executing search when the query model differs from the collection's points.

`SearchResult` preserves the cosine similarity score from Qdrant in `vector_score`, while reciprocal rank fusion stores its fused value in `fused_score`. The `SearchReranker` vector signal reads `vector_score`, and `devops ai rag query` renders cosine beside the final score.
