# Task: `devops gh api rate_limit --jq` Prints the Value That jq Selects (#1886)

**Issue**: [#1886](https://github.com/dan-petty/devops-cli/issues/1886)
**Feasibility**: On 2026-10-23, `uv run devops gh api rate_limit --jq '.resources.graphql.remaining'` failed on origin/main with "Invalid rate_limit payload format from GitHub API". The `-t` and `--verbose` flags failed in the same way. `run_gh` read the stdout of each rate-limit check as the /rate_limit answer, but these flags make gh print different text. `gh api --help` (gh 2.103.1) names the flags that change the printed body. The live `--verbose` output has request log lines before and after the body.

## Description

- [x] **Output flags** (`config/constants.py`, `github/request_classifier.py`): `CONST_GH_API_OUTPUT_VALUE_FLAGS` (`--jq`, `--template`) and `CONST_GH_API_OUTPUT_SWITCH_FLAGS` (`--silent`, `--slurp`, `--verbose`) name the `gh api` flags after which stdout does not end with the response body. The argv parser reads them, and `GhApiArgs.prints_body` is false when one of them is given. `--include` only puts the status line and headers before the body, so it is not an output flag.
- [x] **Rate-limit read** (`github/rate_limiter.py`): `run_gh` reads the quotas from a rate-limit check only when gh prints the answer whole. With an output flag, `run_gh` returns what gh printed and keeps the stored quotas. A rate-limit check with an output flag stays exempt from pacing.
- [x] **Tests**: `tests/test_gh_cmd.py::test_gh_api_prints_the_number_a_jq_filter_selects_from_the_rate_limit` runs the command of the issue, which prints the number and exits 0. `tests/test_github_rate_limiter.py::test_a_rate_limit_check_whose_output_a_flag_changes_returns_it_and_reads_no_quota` covers `--jq`, `-q`, `--template`, `-t`, `--slurp`, `--verbose` and `--silent`. `test_a_rate_limit_check_that_prints_the_answer_reads_the_quota_from_it` keeps the quota read with no flag, with `--include` and with `--paginate`. On origin/main, the command test and each output-flag case except `--silent` failed.
- [x] **Live check**: on 2026-10-23, the command of the issue printed the remaining GraphQL requests and exited 0. The `-t '{{.resources.core.remaining}}'` form printed the remaining core requests.
