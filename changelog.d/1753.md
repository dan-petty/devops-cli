### Added
- ADR 0009 records the evaluation of OpenSpec as the spec and change-proposal layer for agents and task files: it is not adopted, because a change folder repeats what the issue and the task file hold, its archive step conflicts on the shared spec, and replacing task files means rewriting the readiness check, the closing comment and their tests, with the conditions under which to revisit ([#1753](https://github.com/dan-petty/devops-cli/issues/1753)).
