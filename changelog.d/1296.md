### Fixed

- An interrupted `devops ai rag index` resumes every file whose chunks were not all stored (#1296). Until all of its chunks are stored, a file is cached as incomplete. A run without `--force` after a failed batch therefore embeds that file again, and the chunks stored before the failure are overwritten, not duplicated, because chunk ids are deterministic. If the file is deleted or edited before the resume, its stored chunks are still purged.
- Semantic chunks are bounded to 8,192 estimated tokens, which is 32,768 characters at the project's four-characters-per-token estimate, not to 8,192 tokens of the embedding model's tokenizer (#1296).
