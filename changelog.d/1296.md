### Fixed

- An interrupted `devops ai rag index` resumes every file whose chunks were not all stored (#1296). A file is cached only once all of its chunks are stored, so a run without `--force` after a failed batch embeds again any file that spanned that batch. Chunk ids are deterministic, so the chunks stored before the failure are overwritten, not duplicated.
- Semantic chunks are bounded to 8,192 estimated tokens, which is 32,768 characters at the project's four-characters-per-token estimate, not to 8,192 tokens of the embedding model's tokenizer (#1296).
