### Fixed

- `devops k8s deploy-stack --stack infra` (or `all`) creates the Grafana dashboard ConfigMaps again on a cluster Argo CD does not manage (#1297). Since #1279 the root kustomization leaves `k8s/monitoring/dashboards` to Argo CD's `monitoring` Application, so a native deploy applied no dashboards. It now applies that kustomization right after the root one, and its dry run lists it under `kustomizations`. The Argo CD path is unchanged.
