### Fixed

- Argo CD takes the homelab's values from `devops k8s deploy-stack` instead of the repository (#1290). The repository no longer tracks `k8s/devops/configmap.yaml`.
  - deploy-stack renders ConfigMap `devops-cli-config` from `config.yaml`, and no Application owns it.
  - It derives the hosts each of the Applications `devops` and `ingress` renders at the revision Argo CD builds, or at `--argocd-revision`, and writes them onto the Application as Kustomize patches. The `cluster` app-of-apps leaves those patches alone (`ignoreDifferences` with `RespectIgnoreDifferences=true`).
  - It renders everything before it writes, and stops (dry run included) with an error naming the setting when `service.repos`, the machine account or the domain is unset.
  - teardown-stack deletes the ConfigMap.

### Removed

- `devops k8s argocd-source` and its gitignored `.argocd-source.yaml` files: Argo CD reads that file only from the Git repository, so it never saw them (#1290).
