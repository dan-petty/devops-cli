### Fixed

- Argo CD takes the homelab's values from `devops k8s deploy-stack` instead of the repository, replacing the gitignored `.argocd-source.yaml` files of #1279, which Argo CD never read (#1290). The repository no longer tracks `k8s/devops/configmap.yaml`.
  - deploy-stack renders ConfigMap `devops-cli-config` from `config.yaml`, and no Application owns it.
  - It derives the hosts each of the Applications `devops` and `ingress` renders at the revision Argo CD builds, or at `--argocd-revision`, and writes them onto the Application as Kustomize patches. The `cluster` app-of-apps leaves those patches alone (`ignoreDifferences` with `RespectIgnoreDifferences=true`).
  - It renders everything before it writes. It stops, dry run included, with an error naming the setting when `service.repos` or the machine account is unset, and an Argo CD-managed deploy also stops when the domain is unset.
  - teardown-stack deletes the ConfigMap.
