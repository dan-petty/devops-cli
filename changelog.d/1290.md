### Fixed

- Argo CD takes the homelab's values from `devops k8s deploy-stack` instead of the repository (#1290). deploy-stack renders ConfigMap `devops-cli-config` from `config.yaml`, which no Application owns. It writes the configured hosts onto the Applications `devops` and `ingress` as Kustomize patches, which the `cluster` app-of-apps leaves alone (`ignoreDifferences` with `RespectIgnoreDifferences=true`). It renders everything before it writes, and refuses with an error naming the setting when `service.repos`, the machine account or `k8s.domain` is unset. The repository no longer tracks `k8s/devops/configmap.yaml`.

### Removed

- `devops k8s argocd-source` and its gitignored `.argocd-source.yaml` files: Argo CD reads that file only from the Git repository, so it never saw them (#1290).
