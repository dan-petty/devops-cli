# Tasks

Every path below is the path on `main` today. Tests live in the mirror of the package they test, so most paths differ from the flat paths of the issue table.

Two scans list the sites of a file set. Run them over the files of a group, and over no other file.

- Import scan: `uv run ruff check --preview --select PLC2701 --no-fix --output-format concise <files> | grep devops_cli` prints nothing when no file imports a private name of `devops_cli`.
- Patch scan: `uv run ast-grep scan --inline-rules '{id: patch-site, language: python, rule: {any: [{pattern: "patch($$$)"}, {pattern: "patch.object($$$)"}, {pattern: "patch.multiple($$$)"}, {pattern: "patch.dict($$$)"}, {pattern: "monkeypatch.setattr($$$)"}, {pattern: "monkeypatch.delattr($$$)"}, {pattern: "mocker.patch($$$)"}]}}' --report-style short <files>` lists every patch call. No listed call may patch a `devops_cli` name. A call that patches a stdlib or third-party object itself may stay, and the group names it.
- Double scan: `git grep -n -E 'MagicMock|Mock\(' -- <files>` lists inline doubles. None may stand for a `devops_cli` dependency.

Each group changes tests, or renames a private name of `src/` to a public name, with no change of behavior. So no group adds a test that fails on the base. The first task of each group states the base figures, and the last task shows that the scans and the tests give the new figures. Where a group deletes a test, it keeps a line for the pull request: the test name and the reason.
