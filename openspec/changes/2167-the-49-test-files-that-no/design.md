# Design

## Decisions

- **One rule decides how a test reaches code that it patched or imported privately.**
  - Route 1, the default: the test uses the public command, class or function that calls the code, over the shared fakes. This follows `docs/TESTING.md` ("A test reaches private code through the public interface that uses it") and ADR 0007.
  - Route 2: a private function of a domain package (not of `commands/`) that a test checks by its return value gets a public name, and every caller in `src/` and `tests/` takes it in the same step. This holds when route 1 needs a whole tree or a whole review for each example, or when the function is the entry point of its package. Precedent: #1326 gave `is_allowed_review_boundary` and `detect_base_branch` of `src/devops_cli/ai/review/runner.py` a public name. `src/devops_cli/commands/review.py` already imports the five functions of group 15 by their private names, which shows that they are the entry points.
  - Route 3: a private helper of `commands/` is reached through its command. `docs/TESTING.md` says the logic of such a helper belongs in a domain package; moving it is the work of #1323, not of this item.
  - Route 4: a test whose behavior no public route reaches is deleted, with its name and the reason in the pull request (criterion 5 of the issue). The step adds no accommodation to `src/` for it. The tests that the plan expects to delete are `test_volume_reclaim_confirmation_aborted` (group 3), the `_execute_review_workflow` half of `test_no_review_layer_falls_back_to_the_working_directory_for_its_target` (group 15), and any test of group 5 or 9 that the step names.
- **The shared fake replaces the own double, not a patch of the own double.** `ExtendedFakeCoreV1`, `FakeSocraticClient`, `FakeMentalModelClient`, `InMemoryQdrantClient`, `DummyEmbedder` and `_FakeAnalysisClient` are second fakes of edges that `tests/support/fakes/` already fakes. `docs/TESTING.md` says "A test does not build its own double of an edge". Evidence: `FakeCoreV1` already holds `pvs` and `pvcs` (`tests/support/fakes/kubernetes.py` line 331), and `ModelFake` answers structured replies and records calls (`tests/support/fakes/model.py`).
- **A patch of a stdlib or third-party object itself may stay.** `docs/TESTING.md` allows it as the fallback for stdlib edges. Groups 5, 7, 11, 13 and 20 name the calls that stay: `time.sleep`, `subprocess.Popen`, `socket.create_connection`, `subprocess.run`, `logfire.configure`, `logfire.instrument_pydantic_ai`, `httpx2.Client.send` and `shutil.which`. Group 6 patches `httpx2.Client` once, as `stub_web` does in `tests/support/web.py`, because the helper `tests/llm_stream_fakes.py` has no seam for a client that the code under test builds.
- **The checks are repeatable commands, not new tests.** The change alters no behavior, so no group has a test that fails on the base. Three scans give the figures: ruff `PLC2701` for private imports, an `ast-grep` rule given on the command line for patch calls, and `git grep` for inline doubles. They run through tools the repository already has (`ruff` and `ast-grep` are in `uv.lock`). Rejected: a ratchet test that counts the sites. #1309 asked for one, and the owner closed it as not planned on 2026-10-28 because per-file ceilings cost merge conflicts.
- **The command list comes from the public app.** The three tests that read `_COMMAND_SPECS` of `devops_cli.main` use `list_commands` of the Click group of `app` and `DocGenerator().introspect_all_groups()`. Evidence: `list_commands` returns the 40 keys of `_COMMAND_SPECS`, and `CommandGroupDoc` holds `module_path` and the flags of each parameter. The table stays private; `openspec/specs/command-dry-run-class/spec.md` names it in a requirement, and a rename would need a spec delta for no gain.
- **The stack catalogs get the names that #1323 plans.** `MANIFESTS_BY_STACK` and `POST_HELM_BY_STACK` are public data tables that `stack_lifecycle.py`, 14 test files and two documents use. `HELM_RELEASES_BY_STACK` is public already, and `_HELM_RELEASES_BY_STACK` is an alias of it. The alias goes; no shim stays.
- **The groups follow the domains and the 40,000-token budget of one step.** A large file gets named line ranges: `pipeline.py` (136 KB), `runner.py` (63 KB), `networking.py` (50 KB), `test_review_group_analysis.py` (79 KB), `test_architectural_invariants.py` (129 KB). Every group lists the product code it reads, which the first plan left out. Renames go first (group 1), and the helper that other groups call (group 6) goes before them (group 7). After each group the tests that use the changed names pass.

## Existing code to reuse or keep passing

- Fakes and fixtures of `tests/support/`: `process_fake`, `git_fake`, `cluster`, `github_api_and_gh`, `model_fake`, `scanner_fake`, `tool_executor_fake`, `qdrant`, `embedder`, `otlp`, `stub_web`, `roadmap_store`, `config`, `keyring_store`, `clock`, `cli`.
- Public seams: `get_llm_client(transport=, http_client=)`, `KubernetesService.install`, `install_qdrant_client`, `install_embedder`, `WorkspaceIndexer.collect_files`, `DocGenerator.introspect_all_groups`, `run_sandbox_probes`, `compute_workspace_fingerprint`, `inspect_git_manifest_drift`.
- Tests that must keep passing: the importers of `tests/llm_stream_fakes.py` (30 files, group 6), the users of each renamed name (the lists in the groups), `tests/invariants/test_change_folders.py`, and `tests/invariants/test_architectural_invariants.py`.
- Constants and messages stay: `ERRORS.k8s.volume_reclaim_non_interactive`, `MESSAGES.review.tools_not_sandboxed` and the others that the tests read.

## Rejected alternatives

- **Make every private function public.** Rejected: the plan renames about 25 names, each one the unit under test of a domain package, and none of `commands/`. Evidence: `git grep -n -w` of each shows one to three callers in `src/`. A blanket rename would widen the API of 15 modules for no test.
- **Keep the patch sites and add a lint rule that hides them.** Rejected: the acceptance criteria ask for zero sites, and ADR 0007 rejects "allow internal patches with a stated reason" because exceptions accumulate.
- **Add a hook to product code so that a test can reach the interactive prompt of `volume reclaim`.** Rejected: the stdin of `CliRunner` is no TTY (shown in the Feasibility section of the proposal), and a hook that exists for a test is the accommodation that #1307 Q27 deletes. The test is deleted instead.
- **Move the helpers of `commands/k8s/networking.py` into a domain module in this change.** Rejected: #1323 plans that move (its task 2.1). A second plan for the same move would conflict. Group 5 uses the commands.
- **Split the item into one pull request for each domain.** Rejected for this plan: the issue says "Fits in one pull request", and the renames of group 1 touch the files of several domains. The groups are the steps inside the one pull request.
- **Keep the first plan.** Rejected: 39 of the 49 paths of the issue table do not exist on `main`, it names `tests/k8s_fakes.py` that does not exist, its Feasibility holds no command output, and its tasks repeat one template that fits no group.
