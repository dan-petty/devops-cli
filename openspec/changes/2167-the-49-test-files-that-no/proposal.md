# Proposal

## Why

Issue #2167: the test-suite audit of 2026-10-24 found 49 test files that no child of #1307 names. They patch a `devops_cli` name or import a private name of `devops_cli`. ADR 0007 (as the amendment of #2143 states it) and `docs/TESTING.md` forbid both: a test doubles only process edges, through the seam of the edge, and reaches private code through the public interface.

## What Changes

- 43 of the 49 files get the fix. Six files are already clean on `main` (see Feasibility), so the plan leaves them out.
- Each `patch` of a `devops_cli` name goes. The test installs the shared fake of the edge instead: `process_fake`, `git_fake`, `cluster`, `github_api_and_gh`, `model_fake`, `scanner_fake`, `qdrant`, `embedder`, `otlp`, `stub_web` and `config`, all in `tests/support/`.
- Each import of a private name goes. The test reaches the code through its public command or class. Where a pure function of a domain package is the unit under test, the function gets a public name and its callers change.
- Product code that only a patch kept alive goes: the forwarding function `get_k8s_client` in `src/devops_cli/k8s/volume.py` and the alias `_HELM_RELEASES_BY_STACK` in `src/devops_cli/commands/k8s/stack_lifecycle.py`.
- The change adds no behavior and removes none. It alters nothing that a consumer observes, so it carries no spec delta and sets `skip_specs: true`. The two documents that name the renamed catalogs, `k8s/README.md` and `docs/SDLC.md`, change in group 1. The document that names a renamed review function, `docs/SELF_IMPROVEMENT.md`, changes in group 15.
- The plan has 21 groups. Each group fits one implementation step. The whole change fits one pull request, as the issue says.

## Acceptance

Each criterion of the issue maps to the groups that deliver it.

- No test patches a `devops_cli` name or imports a private name of `devops_cli`: groups 1 to 20, and the scans of group 21.
- Each double is a shared fake of `tests/support/fakes/`, installed through its seam or fixture: groups 3 to 5, 7 to 13, 15 to 19 (group 6 keeps the `httpx2.Client` patch of `stub_web` as its precedent; the patches of stdlib and third-party objects that remain are named in the groups).
- Product code that a test needed only for a patch goes: group 1 (the alias `_HELM_RELEASES_BY_STACK`) and group 3 (the function `get_k8s_client`). A patch-only alias that other tests outside this item still use stays, and its owner item removes it: `_is_allowed_review_boundary` in `src/devops_cli/ai/review/runner.py` line 725 is used by `tests/ai/review/test_review.py`, `tests/ai/review/test_review_path.py` and `tests/ai/review/test_review_runner.py`.
- If #1309 has landed, its ceilings go down: none. #1309 was closed as not planned on 2026-10-28, and no ceiling table exists (see Feasibility). No group lowers a ceiling.
- Each test still checks what it checked, and the pull request names each deleted test: groups 3, 5, 9 and 15 list the tests they may delete, and task 21.3 writes the list in the pull request.
- `uv run devops ci` passes: task 21.2.

## Existing Tool Considered

No external tool covers this need. The change uses what the repository and its open tools already give: the shared fakes of `tests/support/fakes/`, `typer.main.get_command` and `DocGenerator` for the command list, `httpx2.MockTransport` through `stub_web`, `ruff` rule `PLC2701` and `ast-grep` for the repeatable scans, and Hypothesis settings for the fixture health check. It builds no new helper, fake or check. It deletes the doubles that copy a shared fake (`ExtendedFakeCoreV1`, `FakeSocraticClient`, `FakeMentalModelClient`, `InMemoryQdrantClient`, `DummyEmbedder`, `_FakeAnalysisClient`) and two forwarding names in `src/`.
