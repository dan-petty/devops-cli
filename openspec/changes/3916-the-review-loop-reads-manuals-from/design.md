# Design

## Decisions

- **Read the manuals from the research collection through `scroll_points` of the client that `src/devops_cli/ai/rag/indexer.py:def resolve_qdrant_client` returns, and keep `load_matched_kb_manuals` as the caller-facing function.**: ADR 0005 makes the reference store the version-pinned source of the review, `qdrant-client` is already locked, and `resolve_qdrant_client` is the seam that the `qdrant` fixture replaces, so a case reaches no network.
- **Build no `src/devops_cli/ai/rag/qdrant.py:class QdrantClient` in the reader.**: That class never reads the installed override and creates its native client from the configured URL, so a case would dial the Qdrant address and the offline criterion would fail.
- **Compare the version range of a record with the version of its component read from the lock files at read time, through the kept `src/devops_cli/ai/kb.py:def _version_matches_pattern`.**: The body requires the version from the lock files at read time, a version stored in the index goes stale when a lock file changes, and `_version_matches_pattern` already compares a pattern with a version through `packaging`.
- **Name a returned manual by `kb:<source_url>@<fetch_date>@<sha16>`.**: The body requires the URL, the date and the hash, and the format keeps `CONST_KB_REFERENCE_PREFIX` with the value `kb:` and the 16 characters that `CONST_KB_SHA_DIGEST_LENGTH` gives.
- **Report an expired record, a record refused at ingest and a mismatched record in the existing drift list, with the reasons `expired`, `refused_at_ingest` and `version_drift`.**: The body requires the drift list to show both new cases, and `src/devops_cli/ai/kb.py:class DriftManual` already carries the path and the reason that `src/devops_cli/review/report.py:676:lines = ["## Reference coverage: drift", ""]` renders.
- **Return no manual and one drift entry when the store is unset or unreachable, instead of raising.**: `src/devops_cli/ai/review/pipeline.py:3173:else tuple(load_matched_kb_manuals(kubernetes_version=self.kubernetes_version)[1])` reads the drift on every report and has no manual seam, and a review of a repository with no store must still render its report; the entry names the gap, so nothing is dropped in silence, and no case builds a client.
- **Pass `kb_manuals={}` at each `run_group_analysis` call site of `tests/review/test_review_group_analysis.py` and `tests/review/test_review_prompt_adversaries.py`.**: `src/devops_cli/review/analysis.py:1510:if kb_manuals is None:` is the seam that keeps a case off the store, and those cases test sampling, replies and plans, not manuals.
- **Leave `filter_kb_manuals_for_group` unchanged, and fill `tools`, `topics` and `tags` of `MatchedManual` from the record.**: The list branch of `src/devops_cli/ai/kb.py:def filter_kb_manuals_for_group` already selects by `m.tools` and `m.tags`, and no production caller passes a mapping, so the record fields keep the group filter working with no edit.
- **Read the manual records and write none: the research store that #3906 delivers writes them.**: The issue names the research store as a dependency, and a writer in this change would duplicate the store that #3906 delivers and would need the fetched-page provenance that only the store holds.
- **Run the before-and-after scoring as a person's process outside the runner pod, and hold both score tables in the pull request comment.**: The review rows need `semgrep` and `osv-scanner`, which the runner image does not hold, and a network to the model gateway, so the comparison is a person's process and not a runner verify.

## Rejected alternatives

- **Keep the front-matter articles as the source of the manuals.**: The articles type a version in the text, so a lock file change drops an article as drift; `src/devops_cli/ai/kb.py:629:def load_matched_kb_manuals(` is the only reader of that metadata, and the issue reports 11 of 59 articles dropped.
- **Build the reader on `src/devops_cli/ai/rag/qdrant.py:class QdrantClient` directly.**: That class never reads the override and creates its native client from the configured URL, so a case would need a live Qdrant server and the offline criterion would fail; `src/devops_cli/ai/rag/indexer.py:459:override = get_qdrant_client_override()` returns the installed fake instead.
- **Store the matched version in the index and compare it there.**: A version stored in the index goes stale when `uv.lock` or the tools lock changes, and `src/devops_cli/ai/kb.py:def _lookup_uv_lock_version` already reads the locked version at call time.
- **Build a new vector store for the manuals.**: `qdrant-client` is already in `uv.lock` and the indexer already writes Qdrant, so a second store duplicates a maintained component and adds a dependency to keep.
- **Raise when the research store is unset, and give every review case the fake.**: `src/devops_cli/ai/review/pipeline.py:3173:else tuple(load_matched_kb_manuals(kubernetes_version=self.kubernetes_version)[1])` runs on every report, so every report case of `tests/ai/review/` and `tests/review/` would need the fake; a reported gap keeps those cases offline and the report honest.
- **Drop an expired, refused or unread record silently.**: The body requires the drift list to show both record cases, and `src/devops_cli/ai/kb.py:class DriftManual` already carries the reason that the report renders.
- **Defer the before-and-after comparison to a follow-up item.**: `tests/fixtures/review_labels/labels.json` and `tests/fixtures/review_labels/sessions` are files of the commit, so the same cases are here and `src/devops_cli/commands/review.py:1855:@app.command("score")` scores them with no gold set from another item.
- **Keep the front-matter matchers after the lookup stops calling them.**: `search_code` for `_evaluate_applies_to` gave 2 hits and for `_process_manual_file` gave 2 hits, all in `src/devops_cli/ai/kb.py`, so the chain is reachable only from `src/devops_cli/ai/kb.py:587:def _process_manual_file(`.

## Unchanged references

- `src/devops_cli/review/analysis.py` (call): It calls `load_matched_kb_manuals(environment=eff_env)` only when `kb_manuals is None`, and the loader keeps that argument; the two modules whose cases pass no `kb_manuals` now pass an empty map.
- `src/devops_cli/ai/review/pipeline.py` (call): It calls `load_matched_kb_manuals(kubernetes_version=self.kubernetes_version)`, which the loader keeps, and the loader reports a gap instead of raising when the store is unset.
- `tests/config/test_setting_overrides_reach_their_readers.py` (call): It already passes `kb_manuals={}`, so it never reaches the store.
