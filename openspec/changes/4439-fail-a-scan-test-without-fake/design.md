# Design

## Decisions

- **Put an executable stand-in for each refused program first on PATH in the floor, and patch no lookup.**: `tests/support/refused_programs.py:23:{CONST_GH_CLI, *(scanner.binary_name for scanner in scanners if scanner is not None)}` names the set, and the refusal stays at the real `shutil.which` and at `tests/conftest.py:def refuse_real_programs`, which is the chosen option of the issue's proposed design.
- **Write the stand-ins once for the run under pytest's basetemp, and put that directory first on PATH for the run, restoring the earlier value at its end.**: `tests/support/host_paths.py:68: Path(tempfile.gettempdir()).resolve(),` allows the run's temporary directory to the host path guard, and the run removes it.
- **Make the fixture session-scoped and autouse, like the two floor fixtures that exist.**: `tests/conftest.py:583:@pytest.fixture(autouse=True, scope="session")` and `tests/conftest.py:662:@pytest.fixture(autouse=True, scope="session")` install the process guard and the host path guard once for the run, and a PATH write before each test would repeat work that the run needs once.
- **Write each stand-in as a `#!/bin/sh` script that exits 127, with mode 0o755.**: Nothing runs the stand-in, because `tests/conftest.py:614:pytest.fail(msg, pytrace=False)` refuses the start first, so the file only has to satisfy the lookup and the binary digest.
- **Keep `scanner_fake`'s PATH replacement unchanged.**: `tests/support/fakes/scanners.py:318: "PATH", os.pathsep.join([str(fake.bin_dir), str(Path(sys.executable).parent)])` makes the scripted stand-in the only scanner found, so the floor stand-in never runs and no host program leaks into a faked test.
- **Assert the scan-without-fake refusal with `match="without a fake"`, which holds both floor messages.**: `tests/conftest.py:610:f"process edge reached without a fake: {target} "` and `tests/conftest.py:652:msg = f"host path reached without a fake: {raw_path}"` are the two messages, and a workstation whose installed scanner the scan resolves first fails with the second one.
- **Add the scan-without-fake case to `tests/commands/test_scan.py`, not to the invariant module.**: That module already has the `runner`, the scan app and `cached_default_ruleset`, and `tests/commands/test_scan.py:71: runner.invoke(scan_app, [sub, str(tmp_path), "--json"]).exit_code` is the scan call the new case mirrors with no fake.
- **Add one new case to `tests/invariants/test_suite_refuses_real_programs.py` and change no case there.**: `tests/invariants/test_suite_refuses_real_programs.py:22:@pytest.mark.parametrize("program", sorted(refused_programs()))` already starts each refused name at a made-up path, which the refusal answers whether or not the program exists, so only a lookup case can fail on the runner before the change.
- **Add no `shutil.which` case for the `scanner_fake` priority.**: `tests/invariants/test_hermetic_floor.py:1037: assert len(paths) == 2` asserts the fake's PATH holds only its stand-ins and the interpreter, and `tests/commands/test_scan.py:79: [Path(run.argv[0]).name for run in scanner_fake.runs],` asserts that the scripted stand-in is the one that ran.
- **Give the helper the constant `REFUSED_STAND_IN_DIRNAME` in `tests/support/refused_programs.py`, so the fixture and the invariant case name the same directory.**: The invariant case asserts that `shutil.which` finds each name under the fixture's directory, and one constant keeps the two from drifting apart.
- **Leave `tests/support/__init__.py` unchanged.**: `references refused_programs` lists it at line 5, and the new names are imported from `tests/support/refused_programs.py`, so the name the package exports today keeps its meaning.
- **Change no existing test for the floor PATH, and make the full suite the census of group 1.**: `tests/support/fakes/process.py:463: monkeypatch.setattr(shutil, "which", fake_which)` hides PATH from every `process_fake` test, `tests/support/fakes/scanners.py:318` replaces PATH for every `scanner_fake` test, and each module that needs a program missing sets its own PATH, as `tests/security/test_sbom.py:96: monkeypatch.setenv("PATH", str(empty_bin))` shows; the count of the remaining tests is unverified, so `uv run devops ci test` stops the step if one is left.

## Rejected alternatives

- **Patch `shutil.which` in the floor so that it reports a refused program as present.**: `tests/invariants/test_suite_refuses_real_programs.py:28: with pytest.raises(pytest.fail.Exception, match=f"real {program}"):` shows the refusal must stay at the process start, and a patched lookup would disagree with `tests/support/fakes/process.py:463: monkeypatch.setattr(shutil, "which", fake_which)`.
- **Skip a scan test on a host that has no scanner.**: `tests/conftest.py:614:pytest.fail(msg, pytrace=False)` fails the test rather than skipping it, and a skip leaves the runner green, which is the defect of #4439.
- **Put the stand-ins in the system temporary directory outside the run.**: `tests/support/host_paths.py:68: Path(tempfile.gettempdir()).resolve(),` allows the root, but a directory outside the run's basetemp is left behind and the host path guard can fail a test that opens it.
- **Commit the stand-in executables under `tests/fixtures/`.**: `tests/support/host_paths.py:68: Path(tempfile.gettempdir()).resolve(),` already allows the run's temporary directory, so no executable needs to enter the repository, where it could start by mistake.
- **Add a new invariant module for the floor PATH.**: `tests/invariants/test_suite_refuses_real_programs.py:22:@pytest.mark.parametrize("program", sorted(refused_programs()))` holds the subject already, and the suite keeps one invariant module for each subject.
- **Add no test for the floor PATH.**: `tests/commands/test_scan.py:71: runner.invoke(scan_app, [sub, str(tmp_path), "--json"]).exit_code` passed on the runner before the change, so no test checked the floor on a host without scanners (#4439).
- **Verify the floor with the invariant module alone instead of the full suite.**: `tests/security/test_sbom.py:96: monkeypatch.setenv("PATH", str(empty_bin))` and `tests/commands/test_scan_outcomes_and_gating.py:135: monkeypatch.setenv("PATH", str(tmp_path / "no-programs"))` are the PATH choices the floor must leave alone, and only the full run checks every module.

## Unchanged references

- `tests/support/__init__.py` (import): The new names are imported from `tests/support/refused_programs.py`, so the package export of `refused_programs` keeps its meaning and the file needs no edit.
