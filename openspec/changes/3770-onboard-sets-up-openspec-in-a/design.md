# Design

## Decisions

- **Add row 16 `openspec` to `devops repos onboard`, after row 15.**: `src/devops_cli/github/onboard/run.py:62:ROW_NAMES: Final[dict[int, str]] = {` holds rows 0 to 15, and `src/devops_cli/github/onboard/run.py:246: run.put(15, lambda: rag_row(writer, ctx, settings))` is the last row, so row 16 is the next free number.
- **Add `MISSING` and `INVALID` to `src/devops_cli/github/onboard/model.py:class RowState` and count both as failing.**: `src/devops_cli/github/onboard/model.py:30:_FAILING_STATES: Final[frozenset[RowState]] = frozenset(` holds the states that make the command exit 1, so a repository without a valid OpenSpec setup needs its two states there.
- **Read the default branch, and read `waiting` while the open template pull request holds the config file.**: Criterion 1 of #3770 names the default branch, and `src/devops_cli/github/onboard/template_pr.py:216:def template_row(` records the head of the open pull request in `ctx.template_head`. Row 9 runs before row 16, so without `waiting` a confirm run that opens the pull request would print `missing` for the files that it just added and exit 1.
- **Take the config file and the specs placeholder from the template of dan-petty/infra, through row 9.**: The issue body says "Do not add a template under `src/`", and `src/devops_cli/github/onboard/template_pr.py:73:def _file_states(` already adds each rendered file that the repository lacks and keeps each file that it holds, so the label rule of #3742 and the OpenSpec files share one pull request with no new write code.
- **Read the config with `get_file_at` on `src/devops_cli/github/client.py:class GitHubClient`.**: `src/devops_cli/openspec/project.py:26:def uses_openspec(source: Path, ref: str, *, operation: str) -> bool:` takes a checkout of the repository, and the onboard run has none.
- **Add `folder_exists_at` next to `src/devops_cli/github/client.py:714: def folder_names_at(self, repo: str, path: str, ref: str) -> tuple[str, ...]:` and answer a folder path in the fake repository.**: `src/devops_cli/github/client.py:687: def get_file_at(self, repo: str, path: str, ref: str) -> str | None:` gives None both for a folder and for no path, and `folder_names_at` gives no name for a folder that holds only `.gitkeep`. The contents API answers a folder with a list, and Git keeps a folder only while it holds a file, so a list answer is the fact that the specs folder exists.
- **Prove the merged tree with a live test that runs the real pinned `openspec validate --specs --strict`.**: `tests/support/fakes/openspec.py:11:The record (`tests/fixtures/openspec_runs/recorded_runs.json`, made by` holds only the commands of the gate and of the archive, and a fixed answer would pass whatever the tree holds; `tests/openspec/test_openspec_contract.py:56:@pytest.mark.live("openspec")` lets the test start the pinned program.
- **Describe row 16 in `docs/repos/onboard.md`.**: `docs/repos/onboard.md:44:| Row | Name | What it does |` is the row table of the command, which criterion 6 names.

## Rejected alternatives

- **Ship a project-neutral config at `src/devops_cli/templates/openspec/config.yaml` and merge it into the files of row 9.**: The issue body of 2026-11-26 says "Do not add a template under `src/`", and `templates/repository/openspec/config.yaml` of dan-petty/infra is that file already; a second copy would drift from it.
- **Write `openspec/specs/.gitkeep` from devops-cli code.**: That is a template file under `src/` in another form. The template of dan-petty/infra is the one home of the files of a new repository, and dan-petty/infra#201 adds the placeholder there.
- **Copy the OpenSpec config file of devops-cli into the target repository.**: `openspec/config.yaml:7:devops-cli is pre-1.0 alpha software` gives the planner of another repository the context of this project.
- **Run `openspec init --tools none` in a scratch checkout and copy the files that it writes.**: Row 9 already delivers the rendered files in the one pull request, and a second write path would open a second pull request or drift from the template.
- **Add `folder_entries_at` that lists every entry of a folder.**: The row needs only to know that the specs folder exists; a list answer of the contents API gives that, and no caller needs the names.
- **Replay the strict validation from the recorded runs of the OpenSpec fake.**: `tests/support/fakes/openspec.py:11:The record (`tests/fixtures/openspec_runs/recorded_runs.json`, made by` holds the commands of the gate and of the archive only, so a replay answers nothing about the merged tree.
- **Report `present` when the open template pull request holds the files.**: Criterion 1 of #3770 names the default branch, so the row would exit 0 while the default branch holds no config file.
