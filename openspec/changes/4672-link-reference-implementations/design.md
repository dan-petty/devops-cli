# Design

## Decisions
- **The step runs inside the alternatives check, after the verdict.** `_check_one` (`src/devops_cli/roadmap/alternatives.py`) makes the check and then calls `ReferenceStep.run`. A failed check runs no step. The research unit #5513 does not exist yet.
- **One package, `src/devops_cli/roadmap/references/`.** `queries` builds the queries, `providers` holds the providers and the counter helper, `mcp_provider` is the optional provider, `candidates` holds the gates and the rank, `relevance` is the decision point, and `step` runs one item in its bounds.
- **GitHub access goes through `RoadmapStore`.** The store gets `search_code`, `search_repositories`, `reference_facts` and a `repository` keyword on `repository_file`. So the in-memory store answers the step in each existing test of the check, and no test of the check reaches GitHub. The two searches use `ListingSession.paginate` with `iterable_key="items"` and stop after one page, so the session paces them on the `code_search` and `search` quota (`src/devops_cli/github/rate_limiter.py:481`).
- **The repository search gives the facts of all code hits in one request.** Its query is a `repo:` qualifier for each repository of a code hit, and `fork:true`. A repository that fails a gate on these facts costs no read of its own. The repositories with the most stars get the reads of the bound first.
- **`reference_facts` is one GraphQL read for a candidate.** It gives the gates again at the head, the commit at the head of the default branch, and whether `HEAD:tests` or `HEAD:test` exists. With REST the same facts cost 3 requests.
- **The token of the search can read private repositories.** `search_code` leaves out a file of a private repository, `ReferenceFacts.private` has no default, and the gate `private` drops a private repository. A query is plain words: a colon and a quote leave it, as in `search_open_items` (`src/devops_cli/github/client.py:942`).
- **Queries.** A rule query is an import statement that `ast` reads, a package name from a URL of the body (`tool_names` of `inventory.py`), or a code span. The merge takes a rule query and a query of the model in turn, and cuts at 3. A body with many code spans then leaves a place for a query of the model.
- **Bounds.** `Budget` counts the code searches (3) and the fact reads (15). A fact read is each request that is no code search. The reads of the candidates leave a reserve of 3 for the verification. The step runs in a thread of its own, and its caller waits 120 s. After the bound the budget is stopped, so the thread sends no new request.
- **A code hit is no prose.** `mimetypes` of the standard library classifies the path. A Markdown, text, reStructuredText or HTML file is no code hit. The probe of 2026-11-26 gave `AGENTS.md` and `docs/agent.md` as the first two hits of an import query.
- **The OSI gate is a table.** `_OSI_LICENSES` in `candidates.py` holds the SPDX identifiers of the OSI-approved licenses that GitHub detects. No dependency of the project holds the OSI list.
- **Rank.** The score is `log10(1 + stars) + log10(1 + direct dependents) + shared PyPI packages + (1 for tests)`. The order of the hits breaks a tie. deps.dev gives the versions that it links to the project of a candidate (the cached read of `inventory.py`, under a new cache key that also holds the version) and the direct dependents of the newest PyPI version.
- **The line range.** The link starts at the first line that holds the longest word of the query, or at line 1, and covers at most 20 lines. The code search gives no line.
- **Documentation.** A documentation hit is a source of the check or a documentation hit of a provider. The step keeps it when its host is on the constant allowlist, its scheme is `https`, the item does not link it, and one streamed `GET` through `http_client(EgressLevel.PUBLIC)` answers 200. A redirect is no answer. The allowlist starts with 8 hosts of the project stack: `ai.pydantic.dev`, `docs.astral.sh`, `docs.github.com`, `docs.pydantic.dev`, `docs.python.org`, `kubernetes.io`, `opentelemetry.io`, `typer.tiangolo.com`. Each is a public host, which the public egress level admits (SECURITY.md rule 2). No egress rule changes.
- **Modes.** `RowMode` (`off`, `plan`, `on`) is the type of ADR 0021 rule 5. Mode `plan` logs each link and counts it with `verified`. Mode `on` gives the links to the check: the block, the comment and `alternatives.refs` hold them, and the writer counts each with `linked` after the write.
- **A change of the links alone posts no comment.** The head commit of a repository moves, so the links move at each recheck.
- **The decision point.** `brain.reference_relevance` has one `Noul` question, `off_need`, so a high probability leaves a candidate out, as `band_of` reads the cuts. Its cuts file holds start cuts with `cases: 0`. `decision_table` puts the point in `FIT_BAR_POINTS`, so the settings accept `shadow` and refuse `on`. The step ignores the band. It asks nothing for a private repository (ADR 0023 section 7).
- **The optional provider is not specific to one server.** `McpCodeSearch` takes the first tool with a `query` argument and reads each link `https://github.com/<owner>/<repo>/blob/<ref>/<path>` of the answer. The step verifies each hit at the head commit, so it trusts no ref of the answer. `RoadmapMcpToolset(optional=True)` makes one connection attempt. The HTTP client of the connection comes from `async_http_client(EgressLevel.PUBLIC)`.
- **The ConfigMap example does not change.** `k8s/` is an environment path that the freeze check refuses (`tests/gate/k8s_checks/environment_freeze.py`), and the default mode needs no key in the ConfigMap.

## Rejected alternatives
- **Call the GitHub session from the providers.** Each existing test of `plan_alternatives` uses the in-memory store and the `web` fake, and `install_transport` takes one transport (`tests/support/fakes/github.py:515`), so a session call would reach no fake in 295 tests.
- **A repository search for each query.** It finds the home repository of a package, which is seldom the repository of a code hit, and it costs 3 of the 15 fact reads. One search with `repo:` qualifiers gives the facts of each code hit.
- **REST reads for the head commit and the tests.** `repos/<r>`, `repos/<r>/commits/HEAD` and `repos/<r>/contents/tests` are 3 requests for a candidate, so 15 fact reads give 3 candidates with no deps.dev fact.
- **Trust the commit of the search hit.** The `html_url` of a code search item holds the commit that the index read (`954e039f...` in the probe), which is not the head. The issue asks for the head commit.
- **Rule queries first.** The body of #4672 holds more than 3 code spans, so no query of the model would be sent.
- **The mode names `off`, `shadow`, `on`.** The owner decision of 2026-11-13 and ADR 0021 rule 5 name `plan`.
- **A setting for the documentation hosts.** A person could then widen egress for a repository. The issue chooses a constant.
- **A hand-written HTTP client for grep.app.** Its plain API answers 429 behind a bot check (#4672), and the project has an MCP client.
- **A parser of the text format of grep.app.** The format has no published contract. A link to a file on GitHub is the same in the answer of each code search server.
- **A new dependency for the OSI list.** `packaging.licenses` holds SPDX identifiers and no OSI flag, and the item adds no dependency.
- **A thread that the step can kill.** Python has none. A stopped budget ends the work after the request in flight, and each request has its own timeout.
