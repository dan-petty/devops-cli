# Proposal

## Why

Agents and the implement runner cannot find the form that runs one check row of `devops ci`, so they try `ci openspec`, `ci test-tree`, `ci --list` and `ci run --only`, and some write a script: 10 of the 25 rows have no subcommand, and a wrong `--only` name exits through `typer.Exit(2)` and leaves no usage record. #5451 makes every row run as a subcommand of `devops ci`, keeps `--only` and `--skip` with a close-name usage error, and removes the unused `devops ci run`.

## What Changes

- Add `CHECK_ROW_NAMES`, the 25 row names in registry order, to `src/devops_cli/commands/ci.py` and register one generated command for each of the 10 rows that has no hand-written command, so each row runs through the same path as a narrowed run of the `ci` group.
- Add one option callback for `--only` and `--skip` that splits the commas, checks each name and raises `BadParameter` with up to 3 close names, and set their help from the row tuple; regenerate the MCP tool listing snapshot that holds the old help.
- Delete the `run` command, update `README.md`, the knowledge base command reference and the docstring of `tests/commands/test_net_construct_rules.py`, and regenerate `docs/CLI_REFERENCE.md`, `docs/commands/ci.md` and `docs/MCP_TOOLS.md`.
- Set the description of `CI_GATE_SLOT_WAIT` to `Time a gate run waited for a free gate slot before its checks started`, which names no removed command, and regenerate its row in `docs/TELEMETRY.md`.
- Add the entries `ci constructs`, `ci docs` and `ci openspec` to `LOCAL_COMMANDS` and write the table that `local_commands_table()` renders into `docs/ROADMAP_WORKFLOW.md`.
- Write the new cases in `tests/commands/test_ci_row_commands.py`, including the tracked-file search for the removed command name, and update `tests/roadmap/implement/test_roadmap_implement_shell_policy.py`, each failing on the base revision.
- The change carries a spec delta because a command, an option, its help text and a metric description are behavior that a caller observes.
- The change fits one pull request.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `ci-gate-rows`: Each row of the check registry is a subcommand, The static row tuple matches the registry, `--only` and `--skip` select a set of rows, A wrong row name is a usage error with a close name, The help of the selection options names the rows, `devops ci run` is removed, The gate-slot metric description names no removed command
- `roadmap-implement-step/inputs`: The prompt lists the local commands of the catalog

## Existing Tool Considered

Click and Typer are the tools the repository already depends on: `typer` and `click` are in `pyproject.toml`, `click.BadParameter` gives exit code 2, and `UsageRecordingGroup` in `src/devops_cli/core/cli.py` already records it as `bad_value`. `difflib.get_close_matches` from the standard library gives the close names. The change builds no tool of its own: it adds one tuple, one option callback and one command generator to `src/devops_cli/commands/ci.py`, which the issue estimates at 0.4 M model tokens and 4 to 6 hours.
