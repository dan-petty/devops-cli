# Design

## Decisions
- **One copy of the shared rules.** The shared rules live only in `renovate/base.json` of dan-petty/infra (ADR 0032: a template that two or more repositories use goes to infra). devops-cli extends it with `github>dan-petty/infra//renovate/base`, the same `github>` preset form that the repositories used for the old path.
- **The old path forwards to infra.** `.github/renovate/base.json` holds only `extends: ["github>dan-petty/infra//renovate/base"]` and a description. Renovate resolves a preset that extends a preset, so a repository that still extends `github>dan-petty/devops-cli//.github/renovate/base` gets the infra rules with no change of its own. #6677 deletes the file after the last such repository changes its `extends` line.
- **The rules of devops-cli stay in devops-cli.** `.github/renovate.json` keeps each rule that only devops-cli uses: the major security fix automerge, the manager file patterns of the environment under `k8s/` (#5134 narrows them), the Grafana plugin datasource, the custom managers and the package rules. The change moves no rule to infra and takes no rule from infra.
- **The validator at the Renovate release of the Service.** The proof of each config is `renovate-config-validator --strict` at 44.239.2, the Renovate release that CronJob `renovate` runs, so the check reads the config as the Service reads it. The validator does not fetch a preset. The CI job "Renovate presets" of infra checks the content of the infra preset.
- **No test reads a config file.** `tests/core/test_renovate_config.py` asserted values of the preset. The scenarios of the specs give the validator command or a live check of the Renovate pull requests, the Dependency Dashboard or the CronJob log.

## Rejected alternatives
- **Extend `github>dan-petty/infra//renovate/k8s` too.** The issue keeps the k8s managers of the environment in devops-cli. The infra preset reads each Application under `k8s/argocd/`, and `.github/renovate.json` reads only `k8s/argocd/apps/`. The infra preset also turns off only an Argo CD git source at `main`, and the rule of devops-cli turns off each git source. The two presets give different updates, so this change keeps the rules of devops-cli.
- **Delete `.github/renovate/base.json` now.** dan-petty/danielpetty.com, dan-petty/devcontainer-features, dan-petty/devtools and dan-petty/vibes extend the old path (contents API, 2026-11-21). Renovate stops with a config error in a repository whose preset is missing, so those repositories would get no update until each one changes its line. #6677 deletes the file after that.
- **Keep the test and point it at infra.** A test that reads a config file and asserts a value goes against #6060. The validator and the CI job of infra check the config.
