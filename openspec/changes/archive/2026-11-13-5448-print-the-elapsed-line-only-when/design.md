# Design

## Decisions

- **Guard `print_elapsed` with `sys.stderr.isatty()`.**: It reads the stderr file descriptor, so `FORCE_COLOR` and `TTY_COMPATIBLE` cannot make a pipe look like a terminal, and `src/devops_cli/telemetry/tracer.py` already guards its export warning with the same call.
- **Keep the elapsed line on stderr and keep it for a terminal.**: A person at a terminal still sees the duration, and stdout stays valid JSON for a pipe.
- **Run the CLI as a python child in the new tests, marked `@pytest.mark.live("python")`.**: The line comes from an `atexit` hook, which `CliRunner` and the in-process `cli` fixture never run, and `docs/TESTING.md:85` forbids a test that imports a private name from `devops_cli`.
- **Give the child `PYTHONPATH` set to `src` under `REPO_ROOT`.**: The editable install names the head checkout, so without the variable the replay of `devops ci fail-to-pass --base origin/main` would import the head source and the new cases would pass on the base.
- **Read the existing tests that import `devops_cli.main` in group 1 and change none of them: `tests/ai/ast/test_treesitter_engine.py`, `tests/invariants/test_dry_run_class_ratchet.py` and `tests/ai/mcp/test_mcp_tool_argv.py`.**: `tests/ai/ast/test_treesitter_engine.py:17:from devops_cli.main import app` and `tests/invariants/test_dry_run_class_ratchet.py:20:from devops_cli import main as main_module` import the module that group 1 changes, so the group lists them in `reads`; the guard keeps every public name of the module, so none of their assertions changes.
- **Read the duration through the `otlp` fixture's `FakeCollector`, and change no line of `src/devops_cli/telemetry/instruments.py`.**: `docs/TESTING.md:248` gives the seam, replacing `emit` would patch a devops-cli attribute, and the instrument and its registry entry stay as they are.
- **Leave the command span and both duration emissions unchanged: `COMMAND_DURATION` from `_delegate` and `SUBCOMMAND_DURATION` from `src/devops_cli/core/cli.py`.**: Both emitters run before the exit hook prints, so the guard removes only the printed line and no duration is lost.
- **Put the new test module in `tests/invariants/test_cli_elapsed_line.py`.**: `src/devops_cli/main.py` sits at the package root, so no folder under `tests/` mirrors it, and `docs/TESTING.md:95` puts a repository-wide invariant test in `tests/invariants/`.
- **Put the pipe, the color-variable and the pseudo-terminal cases in the one test module that group 1 creates.**: The three cases share the child helper and the `atexit` hook they exercise, and a group that changes only a created test module packs no file of the head commit, so the plan check refuses it.
- **Add the new module name to the invariant test list in `docs/TESTING.md` in group 1, and change no line of the source-tree invariant test.**: `tests/invariants/test_source_tree.py:717:def _read_testing_md_invariant_subjects(doc_path: Path) -> frozenset[str]:` reads the list from the document, so the document is the only file that changes.
- **Rewrite only the elapsed part of the JSON section of `CONTRIBUTING.md`.**: The uv `Bytecode compiled` line and the zsh `echo` escape expansion still break a JSON pipe, so the section keeps those causes and drops the elapsed one.
- **Leave the other files that name `Elapsed` unchanged: `openspec/specs/command-error-exit/spec.md` (the delta modifies its requirement), `src/devops_cli/commands/ci.py` (the `Total Elapsed:` line of the CI summary), `src/devops_cli/lang/en/messages.py` (the unused `elapsed_time` key), `src/devops_cli/models/k8s.py` (a duration field of the k8s models), `tests/ci/test_ci_gate_admission.py` and `tests/commands/test_ci.py` (the `Total Elapsed:` assertion), `docs/agent/archive/historical-phases-1-to-50.md` (an archive), `.ast-grep/rules/test-elapsed-upper-bound.yml` (the rule on a test's elapsed time) and `k8s/monitoring/dashboards/cloudnative-pg.json` (a panel title).**: Each names a CI duration, a test bound, an archive or a panel, none of which the guard of the printed line changes, and the delta covers the one requirement that does change.
- **Add no requirement about agent briefs or skills.**: `references` with `Elapsed` lists no file under `.claude/`, `.agents/` or `.kilocode/`, so no brief or skill tells agents to filter the line and no such file changes.
- **Modify the `command-error-exit` requirement that says the entry point prints its `Elapsed` line, and keep all three of its scenarios.**: That sentence becomes false for a piped stderr, and `openspec/specs/command-error-exit/spec.md` must hold the new rule after the archive.
- **Add the terminal rule as a new requirement of the `console-output` capability.**: That capability owns the console streams and their routing, and the new requirement describes where the elapsed line goes.

- **Make the hook public as `print_elapsed` and also test it in process.**: The changed-line coverage gate (`diff-cover --fail-under 90` in `.github/workflows/ci.yml`) does not measure child processes, because `pyproject.toml` has no coverage patch for `subprocess`. With only the child cases, the changed lines of `src/devops_cli/main.py` have 37.5 % coverage. So the hook is public, and two in-process tests in `tests/invariants/test_cli_elapsed_line.py` import it. `docs/TESTING.md:85` forbids only private names.

## Rejected alternatives

- **Remove the elapsed line entirely.**: The issue keeps the duration for a person at a terminal, and its acceptance criteria require the line on a pseudo-terminal.
- **Use Rich `Console.is_terminal` as the guard.**: Rich treats `FORCE_COLOR` and `TTY_COMPATIBLE` as a terminal, so a pipe in such a shell would get the line again, which the third acceptance criterion refuses.
- **Keep the `Elapsed:` workaround in `CONTRIBUTING.md`.**: After the change the CLI writes no line to a pipe, so the workaround would tell agents to filter a line that cannot appear.
- **Replace `emit` with a recorder for the duration case.**: `docs/TESTING.md:85` refuses that patch, and `docs/TESTING.md:248` gives the `otlp` fake that reads the metric.
- **Add a helper module, a setting or a constant for the guard.**: The guard is one condition, and `src/devops_cli/telemetry/tracer.py:1665:if not sys.stderr.isatty():` already calls it inline.
- **Keep the pseudo-terminal case in a group of its own, after the group that changes the code.**: That group changes only the test module that group 1 creates and packs no file of the head commit, so the plan check refuses it; the three CLI cases also share one child helper.
- **Add the three CLI cases to an existing invariant test file.**: `docs/TESTING.md:95` puts one subject in each invariant file, and no existing file of `tests/invariants/` names the elapsed line as its subject.
- **Change the cached stderr console in `src/devops_cli/output/console.py` to carry the terminal check.**: The console is shared by every muted message, and a terminal check there would drop log and warning lines from a pipe too; the issue asks for the elapsed line alone.
- **Change `tests/invariants/test_source_tree.py` to list the new invariant file there.**: `tests/invariants/test_source_tree.py:717:def _read_testing_md_invariant_subjects(doc_path: Path) -> frozenset[str]:` reads the list from `docs/TESTING.md`, so a change to the test file would duplicate the list that the document already holds.
