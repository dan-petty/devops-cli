# Design

## Decisions

- **Keep the Dependencies section of the body as the source of a dependency and add a blocker rule to it.**: The held items declare their blockers as text, and the GitHub blocked-by links hold none of those mentions, so a switch of the source would release no held item.
- **Each `#N` under Dependencies names a blocker, also in prose, unless the text names a link: a block that starts with `None` or `No`, a `#N` after a link word of its sentence (`Part of`, `Child`, `Tracker`, `Related`, `Source`, an owner decision), a sentence with a reverse phrase (`needs this item`, `this item blocks`, `is the parent`, `does not wait for`), a block whose issue merges in either order, and a `#N` in parentheses with other words.**: A missed blocker lets a job take an item while its blocker is open, and a kept mention only holds an item back, so the rule keeps every `#N` that it cannot name as a link. On the 806 open bodies of 2026-11-20 the rule adds no issue to what the base reads, and each open issue that it drops is a tracker or a parent, a related issue, the source line, a reverse link, a `None.` block, an issue that merges in either order, or the tracker in the note of the hold line.
- **Read a sentence end and a line end, outside parentheses, as the end of the scope of a link word or a reverse phrase.**: `Merge first: #4835, child 8 of #4833.` names #4835 and not its parent, `#4550 puts the catalog first. #4691 needs this item.` names #4550, and a line that follows the hold line with no blank line, such as `#4691 needs this item.`, does not drop the hold issue.
- **Read a `#N` in parentheses with other words as a note, and `(#N)` alone as a reference.**: The freeze of #6519 writes `- #6521 (hold: ... of #6519)` as the first item of the Dependencies section of about 130 bodies, and a person lifts every hold when #6521 closes, so the tracker #6519 in the note must hold nothing back. A title with its number, such as `- Child 2 of #4742: "feat(k8s): ..." (#4756).`, keeps its number.
- **Keep the first words of a block with no blocker, the link words, the reverse phrases and the order-free phrases as module constants next to the reader (`_NO_BLOCKER_WORDS`, `_LINK_WORDS`, `_NOT_A_BLOCKER_RE`, `_ORDER_FREE`).**: The rule reads in one place, and a new wording of a link is one entry in one list.
- **Keep each reference of a paragraph that opens with `#N`.**: `tests/roadmap/test_roadmap_consolidate_shortlist.py:174:assert [Signal.LINK in signals(lists, 3, n) for n in (2, 4, 5)] == [True, True, False]` asserts both references of one such paragraph, and `#4884, #4889, #3917. The scheduled reindex waits for #4566.` (#4921) names four blockers. `_section_tokens` reads only the first Dependencies heading of the body, so the line of references that refine writes under `Proposed design` is not read when the person's section comes first (775 of 799 open bodies); the reader must keep the person's prose blockers.
- **Put the blocker rule in `body_dependencies` (`_block_blockers`) and leave `_issues` as the generic reader of `#N` words.**: Every dependency path reads `body_dependencies`, and the quoted-title read needs `_issues` to tell a line that names issues by number from one that names them by title.
- **File the source of a candidate as the line `Source: <source>` under a `## Source` heading after the body, and move the two test assertions that pin the filed-body form with it.**: A heading ends a Dependencies section of level 2 or lower, so the source leaves that section for every source form. Under a level-1 `# Dependencies` heading the `## Source` heading stays inside the section, and a bare `#N` paragraph there would open with `#N`; the `Source:` word keeps that line out of the blocker rule.
- **Read the section with markdown-it-py, which the repository already depends on, and write the blocker rule on its inline tokens.**: The parser tells a heading, a paragraph and a list item apart, so the first word of a line is known, and no new dependency joins the project.
- **Change no caller of `body_dependencies`: the live callers in `src/devops_cli/roadmap/consolidate_shortlist.py`, `src/devops_cli/roadmap/dependencies.py`, `src/devops_cli/roadmap/refine/refine.py` (the proposal and `_edges_of`, the cycle graph of #6505) and `src/devops_cli/roadmap/stage/stage.py` each read the one reader.**: Each caller takes the list of the reader and writes no rule of its own, so each keeps the blocker rule with no change of its own.
- **Let the retry match of `_new_subject` accept the body of `filed_body()` and the form from before this change (`NewCandidate.filed_bodies`).**: The issue body comes from GitHub and only the candidate side comes from `filed_body`. An issue that a run filed before the release ends with the bare `Source:` line, so a run that stopped after filing and tries again after the release would file a second issue if the match took only the new form.
- **Set `CONST_ROADMAP_REFINE_RULES_SINCE` to the time of the fix (2026-11-20T14:03:08Z).**: The narrower rule removes edges, and a change to a rule that sets a next step sets a later time. A wait on a person that the older rule set, such as a dependency cycle that a false dependency made, gets one new round. A blocked wait keeps its recorded blockers (`refine.blocked_by`) until they close, a person replies or a person edits the body; #6515 covers the cycle wait that stays after its edge is gone.
- **Carry the related item #6450 as a related item and not as a dependency of this change.**: The comment of intake names it as a different change that excludes open trackers, and this change excludes every non-blocker mention, so neither delivers the other.

## Rejected alternatives

- **Read the GitHub issue dependencies API (`issues/<n>/dependencies/blocked_by`) as the source of a dependency.**: The API holds typed links only. The items that the issue lists name their blockers as text, so the API would drop each text blocker that an item uses today.
- **Keep every `#N` mention of the section, as the code does now.**: That is the defect: `src/devops_cli/roadmap/refine/refine.py:1239:return [int(word[1:]) for word in words if word.startswith("#") and word[1:].isdigit()]` keeps each word of each inline token, so a parent, a related issue and a source line hold an item.
- **Keep only a line that starts with a blocker opener (`Merge first`, `Depends on`, `Blocked by`, `Waits for`), or whose first word is `#N`, less a clause with a reverse phrase and a `#N` after `of` (the second draft, 12a2cd819).**: On the open bodies of 2026-11-20 it drops real blockers that a sentence opens with other words: the merge order of #5223 to #5236 (`Open the pull request after the pull request of #N merges`), #4968 for #4972 (`The stop test of #4968 must pass first.`), the sibling #4756 for #4761 (`Child 2 of #4742: "..." (#4756).`), #5460 for #5468 (`Issue #5460 gives ...`) and #5506 for #4568. It keeps `This item blocks #5134` (#5298), `#4517 is the parent tracker.` (#5014) and the merge-order note of #6441, and a line that follows the hold line with no blank line can drop #6521 or add a related issue.
- **Keep only a line of issue references, a list item that opens with `#N` and a `Merge first` line.**: The plan review found that this rule drops the prose blockers of 62 open bodies and the `Depends on` lines of 7, and `devops roadmap explain 4867` would then let the stage job take #4867 while #4847 is open.
- **Keep only the first word of a line, whatever the line is.**: `tests/roadmap/test_roadmap_consolidate_shortlist.py:174:assert [Signal.LINK in signals(lists, 3, n) for n in (2, 4, 5)] == [True, True, False]` asserts both references of one paragraph, so that rule would break the test and drop a real blocker.
- **Filter the numbers inside `open_dependency`.**: The cycle graph (`_edges_of`), the consolidate link signal and the stage request read `body_dependencies` with no `open_dependency`, so the false numbers would stay in those paths.
- **Change `_issues` itself to keep only a blocker word.**: The quoted-title read calls `_issues` to tell a line that names issues by number from one that names them by title, so the title read would change with it.
- **Write the source as a markdown link at the end of the body.**: A link text can hold `#N`, and a source may be a path rather than a URL, so the link form fixes no case that the heading does not.
- **Leave the source line at the end of the body and rely on the reader to ignore it.**: The line stays inside the Dependencies section, so each later reader of the section meets it again; the heading removes it for every reader.

## Unchanged references

- `src/devops_cli/roadmap/dependencies.py` (caller): Calls `body_dependencies`, so it keeps the blocker rule with no change of its own.
- `src/devops_cli/roadmap/stage/stage.py` (caller): Builds its dependency list from `body_dependencies`, so it keeps the blocker rule with no change of its own.
- `src/devops_cli/roadmap/consolidate_shortlist.py` (caller): Reads the same reader for its Dependencies signal, so it keeps the blocker rule with no change of its own.
- `src/devops_cli/roadmap/refine/refine.py` `_edges_of` (caller, #6505): Builds the edges of the dependency graph from `body_dependencies`, so a non-blocker mention makes no edge and no cycle, with no change of its own.
