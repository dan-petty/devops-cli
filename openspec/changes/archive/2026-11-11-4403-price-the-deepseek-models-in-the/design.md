# Design

## Decisions

- **A table in the code holds the price of a hosted group that genai-prices does not price.** `_HOSTED_GROUP_PRICES` in `src/devops_cli/ai/spend/pricing.py` is read by the registry only, so it stays in that module (CONTRIBUTING.md, constants). The registry merges it under `ai.price_overrides` and the file of `set-price`: file, then setting, then table, then genai-prices. The price comes with the code, so every process prices the group with no hand step: the Service, its runner Jobs and the workstation. A person can still set another price in the setting or the file.
- **Two keys for one price.** A run of an agent names the route name `deepseek-v4.1-flash-1017`, because LiteLLM writes the route name in the reply body and pydantic-ai reads no reply header. A chat call names the deployment model `openrouter/deepseek/deepseek-v4.1-flash-1017:floor` from the header `x-litellm-model-name`. Both keys point to one `ModelPricing`.
- **The route price is the endpoint that the bill matches.** OpenRouter picks the provider of each call, and its API gives no data policy for an endpoint. The rates of `deepinfra/fp8/flex` on 2026-11-11 match the cost that OpenRouter reported for the calls of the gateway from 2026-11-08 to 2026-11-11 within 7%, for each of the three callers. The old gateway rates of 2026-11-02 read 20% to 117% high. A person confirms the rates on the account activity of OpenRouter (#4422).
- **A cached input rate, optional.** `ModelPricing.cache_read_usd_per_million` and `AIPriceOverride.cache_read_usd_per_million` default to None, and None keeps the prompt rate for every prompt token. So a price that names no rate costs what it cost before. `cache_read_tokens` counts inside `prompt_tokens`, as the OpenAI usage, pydantic-ai and genai-prices count them.
- **genai-prices gets the cached tokens too.** `_genai_prices_cost` passes `cache_read_tokens` in `genai_prices.Usage`, so a run on a Claude group costs the cache-read rate of genai-prices. That rate is the rate in the gateway config for both Claude groups, and the test checks it.
- **The gateway config holds the same rates, and a test holds them together.** The gateway records the cost that OpenRouter reports, so its `model_info` rates are a fallback. They are set to the same three rates so that the repository has one price for the group. The test compares the client cost of each hosted group with the cost at the `model_info` rates of the group, for a call with cached tokens below the 100,000-token tier of Haiku.
- **Agent runs first, chat calls later.** `record_run_spend` gives the cached tokens of each reply. The chat path of `LLMClient` reads no cached tokens from a reply, so it keeps the prompt price for every prompt token, which reads high and never low. It holds 14 of the 2,483 DeepSeek rows of the workstation ledger.

## Rejected alternatives

- **Only an `ai.price_overrides` entry `deepseek-v4.1-flash-1017:floor` in the ConfigMap template, at 0.05 and 0.192 USD (the refine design).** The 2,469 `agent_run` rows of the workstation ledger name the route name, not that key, so 99% of the tokens stay at $0. With no cached input rate, the client would record about 24 USD a day for about 5 USD of real cost. The template reaches the Service only when a person applies the live ConfigMap, and it never reaches the workstation.
- **Upgrade genai-prices to 0.2.3.** Its price for the snapshot is the DeepSeek list price (0.30 and 1.20 USD), about 4 to 5 times the route price, so the spend would read high. The release is one day old, and the minor version moves from 0.1 to 0.2, while the registry uses private names of the package (`_bundled_snapshot`, `_providers_from_raw`).
- **A default value of `ai.price_overrides`.** A config file or ConfigMap that sets the setting replaces the whole default map, and the live ConfigMap sets it for the two reference models. The DeepSeek price would then be lost in the Service.
- **The rates of the cheapest fp8 endpoint (Morph: 0.022, 0.004 and 0.40 USD).** At these rates the three callers cost 13.57, 2.48 and 0.75 USD against the recorded 12.69, 1.87 and 0.53 USD (7% to 42% high), so the route does not send most calls there.
- **The standard rates of DeepInfra fp8 (0.098, 0.0029 and 0.294 USD).** The three callers cost 25% to 31% more than the recorded cost.
- **Read the cost from the gateway reply (`x-litellm-response-cost`).** A run of an agent reads no reply header (#3665), and a streamed reply sends its headers before the cost is known.
- **Strip the OpenRouter suffix `:floor` from a model name in the lookup.** It is a string rule of our own for one provider. Two keys in the table are explicit, and the test fails when one is missing.
