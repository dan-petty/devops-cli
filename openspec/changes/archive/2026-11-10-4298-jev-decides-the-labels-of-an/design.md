# Design

## Decisions
- **One request, one proposal.** `JevIntakeModel.propose` sends one request with all questions. Questions are keyed `type`, `priority`, `value`, `effort` and `duplicate_of_<number>`. One request is one round trip and one input-token charge for the shared state.
- **Choice for type and priority, score for Value and Effort.** The type and the priority have names, so they are choices. Value and Effort are ordered, so each is a score with three levels (Low, Medium, High from level 0). The level is the rounded score. The cookbooks use choices for classes and scores for ordered matching.
- **Yes/no for duplicates, high bar.** A nearest item is the possible original only when `noul >= 0.90` (`CONST_ROADMAP_JEV_DUPLICATE_THRESHOLD`). A false duplicate is worse than a missed one (owner rule of 2026-10-25). The verdict only flags: intake places the candidate and closes nothing. When two items reach the bar, the higher probability is named. Jev writes no text, so `shared_change` is the title of the flagged item; the reason line states the probability.
- **Same `ModelProposal`.** Jev builds the `ModelProposal` of the `triage` model, so `validate_proposal`, the cap of P0, the evidence checks and the judge of the shortlist run for real. No second path decides what stands.
- **Fail open, as a whole.** A failed request (`ModelAPIError`, `UnexpectedModelBehavior`, `UserError`, `DevOpsCLIError`, `OSError`) or a confidence below 0.60 on a choice or score sends the whole request to the `triage` model. A mix of fields from two models has no single reason. The failure is logged as a warning and counted, so it is not swallowed. A failure of the `triage` model after the fallback stays as it is today.
- **A comparison mode without fallback.** `JevIntakeModel(..., fall_back=False)` raises `UnusableProposalError` on a failure, which the existing evaluation counts as a skipped candidate, and sends no counter. `devops roadmap eval jev` uses it so that the report compares Jev alone.
- **The type descriptions come from `.github/labels.yml`.** `ProposalRequest.type_notes` carries `(label, description)` pairs, and `needs_type` says whether a type is asked. Both stay out of the JSON of the `triage` message (`as_json` drops them), so its prompt and snapshots do not change.
- **The metric has no `repo` label.** Fields and outcomes are two small enums: 5 x 2 = 10 series. A `repo` label would multiply them by the number of repositories and answers no question that the fallback rate does not.
- **Spend bound.** The comparison makes two calls for each case (82 for 16 duplicate and 25 label cases). `--max-calls` (default 160) stops a larger run before its first call. At about 0.042 USD for 1M input tokens of Jev and a few cents for the `triage` model, a run costs well under 1 USD.
- **Offline label set.** `intake_label_cases.json` holds 25 closed issues with the type, priority, Value and Effort that a person set, picked at random per (Value, Priority) bucket with a fixed seed from the closed issues that hold one label of each family. The bodies are cut to 400 characters. No case holds a host name, an address or an e-mail address.

## Rejected alternatives
- **Replace the `triage` call for good.** Rejected: Jev is not reachable yet (#4289, a 404), and no measurement of its false duplicates exists. The setting and the fallback let a person decide after the comparison.
- **Per-field fallback.** Rejected: a proposal that mixes two models gives reasons from two sources, and the counter would hide which model decided the placement. The whole-request fallback costs one extra `triage` call only when Jev fails.
- **Ask Jev for the evidence of a P0.** Rejected: Jev writes no text, and the evidence must be copied character for character from the candidate. A regular expression over the text would be a hand-written parser, and the numeric kinds (`failed_run`, `regression_commit`) match any number. P0 stays with verified evidence from the `triage` path and with a person.
- **Replace the type from the Conventional Commit title.** Rejected by the issue: the title gives `type/*` and `scope/*` deterministically (#2715), and Jev is asked for a type only when the title gives none.
- **A hand-written fake of `DecisionModel`.** Rejected: a fake at the transport lets `SystemOneModel` build the wire request and reject an answer that the endpoint would not send.
