# Design

## Decisions

- **The subject is the words of the clause before the read word.** A clause starts after a `,`, `;`, `:`, a parenthesis, or a word such as `and`, `so`, `because`, `after`, `by`, `that` or `which`. A relative pronoun, `and` or `or` with no word after it shares the subject of the words before it ("the code that reads", "it fetches the head and reads"). A comma, `and` or `or` with no word after it makes the read a verb of a list, and the subject of the list is in the words back to a `;`, `:`, a parenthesis or a word that starts a new clause. So "I listed `src/`, opened `x` and read `y`" is a claim, and "the replay lists `x`, checks `y` and reads `z`" is not. A comma is no list mark for `reading`, which is its own subject ("After the probe, reading `x` shows").
- **An empty subject is a claim of the run.** Articles, determiners, auxiliary verbs and adverbs name no reader. So "Read `x`", "Reading `x` shows", "the same read shows" and "`x` was read" stay claims, as before. A noun read, `read` or `reads` before `of` or a verb of its result ("a quick read of `x`", "both reads of `x`"), has no subject. A participle `read` after a comma or a code span and before a preposition ("`x`, read at the base, shows", "`x` read from GitHub") is a passive, and so is a verb of a list after a passive ("`x` was copied and read"). Only a subject with another word is no claim, unless the word names the run or its author: `I`, `we`, `my`, `our`, `run`, `runs`, `planner`, `agent`.
- **The object is the path that the read takes.** The tool name of a span `read_file path` takes the path of that span. A participle takes the last path before it. For a passive it is the first path of the subject. Else it is the first path after the read word, up to `;`, a comma before a new clause, or a verb of the result such as `shows`, `showed` or `gave`. With no path in its object, the read reads the last path before it in the sentence, so "`read_file` on it showed the text `x.py`" and "the same file" keep their claim of the earlier path, and a path in the result is not the object. A pronoun at the start of the object (`it`, `them`, `that file`, `the same file`) makes the read take the last path before it also when a path comes after the pronoun, so a result verb that is not in the list ("revealed") does not make the path of the result the object. With no path before it, the read reads the first path of its result, as in "the same read shows `x.py:3`". A sentence with no such path makes no path claim.
- **A search match supports a citation of its line only.** `ToolCallRecord.matches` holds the `path:line` of each match line of a `search_code` or `callers` answer, and `TraceFacts.lines` joins them. A `path:line` or `path:line:text` citation of such a line is seen. A bare path and a line range are not, because the run saw one line. Only a read whose object is the citation itself is supported: `read_file`, and a read that takes the line through a pronoun or from its result, claim the whole file, so only a read path supports them (#3205).
- **A probe line is no read.** The gate already removes a quoted probe sentence (#4463), and "the probe reads" now has a subject that is not the run.

## Rejected alternatives

- **Exempt a list of subjects (`the plan`, `the group`, `the probe`).** Each new subject would cause one more false refusal. The change lists the reader words instead.
- **Count every path of a search answer or a probe line as read.** It would accept a claim of a whole file from one line, and of a path that the probe says is no file.
- **A dependency parser (spaCy).** It needs a model download and a large dependency, and it does not read code spans. The gate needs only the clause of one word.
- **Only a list of pronoun objects, or only a list of result verbs.** A pronoun list does not find the object of "`x.py`, read with `read_file`, shows `y.py`", which has no pronoun. A list of result verbs does not end the object at a verb that is not in the list, as in "`read_file` on it revealed `y.py`". The gate uses both.
- **Keep the first path of the sentence when the read has no object.** It refuses the search hit of #3453, which a later clause names.
